F1 正反拆解：边界在哪

本概念的边界不是「是它 / 不是它」，而是「哪一条定理管哪一对子空间」。

边界例 2 ⭐ 「同维 ⟹ 同构」只在有限维成立 本卡「ker⁡T≅V/im⁡T\ker T\cong V/\operatorname{im}T」这一条依赖有限维（有限维空间必有补空间，且同维必同构）。无限维空间中「维数都是无穷大」推不出同构。 > 「秩零化定理」在多数教材里就是按有限维讲的。无限维版本需要额外的集合论结果，请勿跨场合套用。

边界例 3 ⭐ 同构「存在」，但不「由 TT 决定」 组 B 里 V/im⁡TV/\operatorname{im}T 与 ker⁡T\ker T 都是 11 维，同构当然存在。但由 TT 的公式直接诱导的映射在那里恰好合法（因为 TT 把 im⁡T\operatorname{im}T 整个打成 𝟎\mathbf0）；而在组 A 里同一个构造就不合法（见下方反例第一行）。 ⟹ 两个例子里「V/im⁡T≅ker⁡TV/\operatorname{im}T\cong\ker T」都成立，但没有一个统一的、由 TT 单独决定的构造 —— 这条同构是非典范的。

F2 通俗理解

一句人话：每个线性变换都能换一组基，让它的矩阵只剩「上面一块随便、下面全零」；丢掉的那部分和补上的那部分，形状一定一样。

类比 · 书架与「空出来的层」 > 一排书架（VV）被一台复印机（TT）扫过一遍：扫过的部分变成「成品区」（im⁡T\operatorname{im}T），还有一些格子它「完全扫不动 / 没扫到」，那几个格子构成核。 > 关键在于：你可以换一种方式重新给这些格子编号。按「成品区在前、空格子在后」排，复印机对任何一格的输出都落在前面的成品区 ⟹ 矩阵下面那一大片必然全是零。 > 至于「空出来的那几个格子」长什么样 —— 它的维数被成品区牢牢钉住：成品区 rr 格 ⟹ 空格子必是 n−rn-r 个。

失效边界（三条） - 类比只告诉你「维数被钉住」，不能告诉你「核就等于那些空格子」 —— 组 B 就是反例：真正的补空间得另选，选出来的 WW 与核只是同维，不是同一块地方。 - 「扫不动」不是「扫成某张废纸」，是扫成空白（𝟎\mathbf0）。 - 类比只帮想到，不作证明依据。

为什么需要它：它是「把抽象的核与像换成能算的东西」的通行证 —— 换基成上块 + 下零、判可约与不可约、进 Jordan 标准形与同态基本定理（都是更后面的工具），全靠这一步。

F3 严格数学表述

三条定理：先分清哪条配哪一对

编号 结论 地位 同构由谁给出
T1 V/ker⁡T≅im⁡TV/\ker T\;\cong\;\operatorname{im}T 定理（第一同构定理） 典范：映射就是 φ(𝐯+ker⁡T)=T𝐯\varphi(\mathbf v+\ker T)=T\mathbf v
T2 ker⁡T≅V/im⁡T\ker T\;\cong\;V/\operatorname{im}T 定理（秩零化定理） 存在，但非典范：必须另选补空间（或内积）才能拿到同构
T3 dim⁡ker⁡T+dim⁡im⁡T=dim⁡V\dim\ker T+\dim\operatorname{im}T=\dim V 定理（秩–零度） 维数版，只是数，不给同构

记法提醒：V/WV/W 是「商空间」＝ 把 WW 里的向量全看作同一个陪集的 VV，V/ker⁡TV/\ker T 是「把核里的全看作同一个」，V/im⁡TV/\operatorname{im}T 是「把像里的全看作同一个」。陪集里的分子不唯一，这正是下一步要验良定义性的原因。

T1 的证明（逐句，每步注依据）

命题：φ:V/ker⁡T→im⁡T\varphi:V/\ker T\to\operatorname{im}T，φ(𝐯+ker⁡T)=T𝐯\varphi(\mathbf v+\ker T)=T\mathbf v 是同构。

  1. 良定义：若 𝐯+ker⁡T=𝐯′+ker⁡T\mathbf v+\ker T=\mathbf v'+\ker T，则 𝐯−𝐯′∈ker⁡T\mathbf v-\mathbf v'\in\ker T，即 T(𝐯−𝐯′)=𝟎T(\mathbf v-\mathbf v')=\mathbf0，故 T𝐯=T𝐯′T\mathbf v=T\mathbf v'。依据：陪集相等的定义 ++ 核的定义。
  2. 线性：φ(α(𝐯+ker⁡T)+β(𝐯′+ker⁡T))=φ((α𝐯+β𝐯′)+ker⁡T)=T(α𝐯+β𝐯′)=αT𝐯+βT𝐯′\varphi(\alpha(\mathbf v+\ker T)+\beta(\mathbf v'+\ker T))=\varphi((\alpha\mathbf v+\beta\mathbf v')+\ker T)=T(\alpha\mathbf v+\beta\mathbf v')=\alpha T\mathbf v+\beta T\mathbf v'。依据：陪集的加法定义 ++ TT 的线性。
  3. 满射：任意 𝐮∈im⁡T\mathbf u\in\operatorname{im}T 按定义有 𝐮=T𝐯\mathbf u=T\mathbf v，于是 φ(𝐯+ker⁡T)=𝐮\varphi(\mathbf v+\ker T)=\mathbf u。依据：像的定义。
  4. 单射：φ(𝐯+ker⁡T)=𝟎⇒T𝐯=𝟎⇒𝐯∈ker⁡T⇒𝐯+ker⁡T=𝟎+ker⁡T\varphi(\mathbf v+\ker T)=\mathbf0\Rightarrow T\mathbf v=\mathbf0\Rightarrow\mathbf v\in\ker T\Rightarrow\mathbf v+\ker T=\mathbf0+\ker T。依据：核的定义 ++ 陪集的定义。◼\blacksquare

第 1 步是整条证明的心脏。T2 那条映射（陪集用 im⁡T\operatorname{im}T）在这里就崩：良定义需要 T(𝐯−𝐯′)=0T(\mathbf v-\mathbf v')=0 对一切 𝐯−𝐯′∈im⁡T\mathbf v-\mathbf v'\in\operatorname{im}T 成立，等于要求 T(im⁡T)={𝟎}T(\operatorname{im}T)=\{\mathbf0\}，一般不成立（组 A 即反例）。

T2 的证明（三步）

  1. 有限维下，im⁡T\operatorname{im}T 的任何子空间都有补空间 WW，使 V=im⁡T⊕WV=\operatorname{im}T\oplus W。依据：有限维子空间的直和分解存在性。
  2. 于是 dim⁡W=dim⁡V−dim⁡im⁡T\dim W=\dim V-\dim\operatorname{im}T。依据：直和的维数可加。
  3. 由 T3（秩–零度），dim⁡ker⁡T=dim⁡V−dim⁡im⁡T=dim⁡W\dim\ker T=\dim V-\dim\operatorname{im}T=\dim W，两有限维空间同维 ⟹ 同构。◼\blacksquare

注意 T2 的同构「没有给出配方」 —— 因为要先选 WW。要写出配方，就得额外给一个内积：此时 V/im⁡T≅(im⁡T)⟂=ker⁡TV/\operatorname{im}T\cong(\operatorname{im}T)^{\perp}=\ker T（用 u+im⁡T↦(u,⋅)u+\operatorname{im}T\mapsto(u,\cdot) 这个对偶型配方）。这就是「非典范」的确切含义。

实用推论：换基后的矩阵形状

设 WW 如 T2，im⁡T\operatorname{im}T 的一组基为 γ1,…,γr\gamma_1,\dots,\gamma_r（r=dim⁡im⁡Tr=\dim\operatorname{im}T），WW 的一组基为 δ1,…,δn−r\delta_1,\dots,\delta_{n-r}。在基 ℬ′=(γ1,…,γr,δ1,…,δn−r)\mathcal B'=(\gamma_1,\dots,\gamma_r,\delta_1,\dots,\delta_{n-r}) 下：

  • 对 j≤rj\le r：Tγj∈im⁡TT\gamma_j\in\operatorname{im}T ⟹ 它的 ℬ′\mathcal B' 坐标的后 n−rn-r 个分量全为零 ⟹ 第 jj 列形如 (*𝟎)\begin{pmatrix}\ast\\ \mathbf0\end{pmatrix}
  • 对 j>rj>r：Tδj∈ker⁡TT\delta_j\in\ker T，而 ker⁡T\ker T 一般不落在前 rr 个方向里 ⟹ 无约束

⟹ TT 在这组基下的矩阵形如

(AB𝟎n−r𝟎),A∈ℝr×r,B∈ℝr×(n−r)\begin{pmatrix} A & B \\ \mathbf 0_{n-r} & \mathbf 0 \end{pmatrix},\qquad A\in\mathbb{R}^{r\times r},\ B\in\mathbb{R}^{r\times(n-r)}

两个术语（考试爱考） - 可约（reducible）：im⁡T∩ker⁡T={𝟎}\operatorname{im}T\cap\ker T=\{\mathbf0\}。此时可直接取 W=ker⁡TW=\ker T，矩阵进一步简化为 (A000)\begin{pmatrix}A&0\\0&0\end{pmatrix}，其中 A=[T|im⁡T]A=[T|_{\operatorname{im}T}] 可逆（由 T1）。 - 不可约（irreducible）：ker⁡T⊆im⁡T\ker T\subseteq\operatorname{im}T。此时 T|im⁡TT|_{\operatorname{im}T} 是幂零的（im⁡Tk\operatorname{im}T^k 递减而有限维 ⟹ 稳定 ⟹ 该限制幂零）。组 B 即是：TT 把 xx 轴上的 (1,0)(1,0) 打成 𝟎\mathbf0，A2=𝟎A^2=\mathbf0。

「零化」这个名字来自 V→V/im⁡TV\to V/\operatorname{im}T 这个「把像压掉」的操作；它不能消掉 im⁡T\operatorname{im}T 内部的那部分核 —— 不可约时那部分是消不掉的。

操作骨架：怎么用

① 想知道 TT 压掉几维 ⟹ dim⁡ker⁡T\dim\ker T；② 想知道输出范围多大 ⟹ dim⁡im⁡T\dim\operatorname{im}T；③ 想把 TT 化成最简矩阵 ⟹ 找 W∥im⁡TW\parallel\operatorname{im}T，按「像的基在前、WW 的基在后」排序，矩阵自动呈上块 + 下零；④ 想判可约 ⟹ 算 im⁡T∩ker⁡T\operatorname{im}T\cap\ker T（可算法见下）。

F4 几何 / 物理意义
  • 补空间 ==「剩下的那部分」：VV 切成「已经变成像的那些方向」++「仍待在原地的部分」。后者的维数被前者牢牢钉住：像 rr 维 ⟹ 剩下 n−rn-r 维 ⟹ 与核同维。
  • 组 B 的画面最该看：T(x,y)=(y,0)T(x,y)=(y,0) 里，像 == 核 == xx 轴，而那条 yy 方向的「多出来的一条」谁也拿不走 —— 这就是为什么不能写「V=ker⁡⊕imV=\ker\oplus\operatorname{im}」，只能写「存在 WW」。
  • 回指 F3：「矩阵呈上块 + 下零」的画面，就是「把已变成像的方向排在前面」的坐标选择结果 —— 不是 TT 变简单了，是我们换了个坐标系看它。
  • 物理类比：im⁡T\operatorname{im}T 是「输出端真正能出现的态」，ker⁡T\ker T 是「输入里那些完全不被听见的分量」。补空间 WW 是「为了凑齐维度而另找的、与核同维但不是核的那部分方向」—— 提醒你：同维不等于同一块地方。
  • 纪律：几何只帮你想到，结论一律以 F3 的推理为准。

🧮 概念计算器（输入 → 输出）

「可约 / 不可约」这件事最容易口头含混，所以给它一个能算的函数：输入 AA，输出三个维数、重叠维数与直和判定。

import numpy as np
def split(A):
    A = np.array(A, dtype=float); n = A.shape[1]
    r = int(np.linalg.matrix_rank(A))
    ov = r - int(np.linalg.matrix_rank(A @ A))
    return {"秩/像维数": r, "核维数": n - r, "补空间维数": n - r,
            "im∩ker维数": ov, "直和成立": "是" if ov == 0 else "否", "核对(核+像)": (n - r) + r}
for name, A in [("组A", [[1, 1], [1, 1]]), ("组B", [[0, 1], [0, 0]])]:
    print(name, " ".join(f"{k}={v}" for k, v in split(A).items()))
# 预期输出:
# 组A 秩/像维数=1 核维数=1 补空间维数=1 im∩ker维数=0 直和成立=是 核对(核+像)=2
# 组B 秩/像维数=1 核维数=1 补空间维数=1 im∩ker维数=1 直和成立=否 核对(核+像)=2
split = \(A) {
  A = matrix(as.numeric(A), nrow = 2, byrow = TRUE)
  n = ncol(A); r = qr(A)$rank; ov = r - qr(A %*% A)$rank
  parts = c(paste0("秩/像维数=", r), paste0("核维数=", n - r), paste0("补空间维数=", n - r),
            paste0("im∩ker维数=", ov), paste0("直和成立=", if (ov == 0) "是" else "否"),
            paste0("核对(核+像)=", (n - r) + r))
  cat(paste(parts, collapse = " "), "\n")
}

常见错位清单（〔〕内是错误来源）

  1. 〔定理当定义〕三条定理混着背：把「典范的 V/ker⁡≅imV/\ker\cong\operatorname{im}」与「非典范的 ker⁡≅V/im\ker\cong V/\operatorname{im}」配对搞反。
  2. 〔类比越界〕从维数相加推出「V=ker⁡⊕imV=\ker\oplus\operatorname{im}」或「集合互补」。
  3. 〔字眼漏读〕「存在补空间 W∥im⁡TW\parallel\operatorname{im}T」被读成「W=ker⁡TW=\ker T」。
  4. 〔量词顺序〕陪集里的分子不唯一，却没验良定义性就写 φ(𝐯+⋯)=T𝐯\varphi(\mathbf v+\cdots)=T\mathbf v。
  5. 〔字眼漏读〕忽略「有限维」——无限维里「同维 ⇒\Rightarrow 同构」失效。
  6. 〔定理当定义〕以为「零化」能把 im⁡T\operatorname{im}T 里那部分核也消掉；不可约时 T|im⁡TT|_{\operatorname{im}T} 幂零，那部分消不掉。
