## F1 正反拆解：边界在哪

### 正例：四个不同的 $A$，四种「特殊方向」

| $A$ | 特征值 | 每个特征值的一组特征向量 | 独立方向数 |
|---|---|---|---|
| $\begin{pmatrix}2&0\\0&1.5\end{pmatrix}$ | $1.5,\ 2$ | $(1,0)^{\mathsf T}\ ;\ (0,1)^{\mathsf T}$ | 2 |
| $\begin{pmatrix}1&1\\1&1\end{pmatrix}$ | $2,\ 0$ | $(1,1)^{\mathsf T}\ ;\ (1,-1)^{\mathsf T}$ | 2（且**正交**） |
| $\begin{pmatrix}0&1\\0&0\end{pmatrix}$ | $0$（二重） | $(1,0)^{\mathsf T}$ | **1** |
| $\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ | $\pm i$ | 实数范围内**不存在** | — |

验算要点：$\begin{pmatrix}1&1\\1&1\end{pmatrix}$：$f(\lambda)=\lambda^2-2\lambda=\lambda(\lambda-2)$ ⟹ $\lambda=0,2$；$\lambda=2$ ⟹ $A-2I=\begin{pmatrix}-1&1\\1&-1\end{pmatrix}$ ⟹ $y=x$ ⟹ $(1,1)^{\mathsf T}$ ✓；$\lambda=0$ ⟹ $A\mathbf v=0$ ⟹ $(1,-1)^{\mathsf T}$ ✓；内积 $=1-1=0$ ✓。

### 边界例 ⭐（三个）

**边界例 1 · $\lambda$ 可以是 $0$，但 $\mathbf v$ 绝不能是 $\mathbf0$（两者地位完全不同）**

$A=\begin{pmatrix}0&1\\0&0\end{pmatrix}$：特征值**只有 $\lambda=0$**（$f(\lambda)=\det\begin{pmatrix}-\lambda&1\\0&-\lambda\end{pmatrix}=\lambda^2$，二重根），特征向量是 $\{(1,0)^{\mathsf T}\}$。
验算：$A(1,0)^{\mathsf T}=\mathbf0=0\cdot(1,0)^{\mathsf T}$ ✓。
> 「特征值可以是 $0$」与「特征向量可以是零向量」——前者**成立**，后者**违反定义**。这个区分是本卡删条件实验的核心，也是解题时最常被跳过的一句。

**边界例 2 ⭐ 代数重数 $\ge$ 几何重数**

$A=\begin{pmatrix}1&1\\0&1\end{pmatrix}$：$\det(A-\lambda I)=(1-\lambda)^2$ ⟹ $\lambda=1$，**代数重数 $2$**；$\ker(A-I)=\{(x,0)^{\mathsf T}\}$ ⟹ **几何重数 $1$**。
⟹ 只有**一个**特征方向 ⟹ **不可对角化**。这是「特征值算出来了，变换还是不好办」的根源。

**边界例 3 ⭐ 实矩阵也可能有复特征值**

$A=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$（旋转 $90^\circ$）：$\det(A-\lambda I)=(-\lambda)(-\lambda)-(-1)(1)=\lambda^2+1$ ⟹ 在**实数范围内无根**（$\lambda=\pm i$）。
> 若把 $\lambda$ 限定在实数，这张矩阵「没有特征向量」—— 可它是最标准的变换之一。**这说明特征值必须允许复数**，否则许多变换会「丢失特征值」。当然，**实对称矩阵的特征值一定是实的**（见 F3 的定理）。

### 反例（三条）

| 常见说法 | 反例 | 错在哪 |
|---|---|---|
| 「$\mathbf0$ 是特征向量」 | $A\mathbf0=\lambda\mathbf0$ 对任意 $\lambda$ 都成立；允许零向量后，$A=\begin{pmatrix}2&0\\0&3\end{pmatrix}$ 的 $5$、$\pi$ 全都「成立」 | 定义里 $\mathbf v\ne\mathbf0$ 是命门 |
| 「$A\mathbf v=\lambda\mathbf v$ 对任意 $\mathbf v$ 都成立」 | $A=\begin{pmatrix}2&0\\0&3\end{pmatrix}$，$\mathbf v=(1,1)^{\mathsf T}$：$A\mathbf v=(2,3)^{\mathsf T}$，不存在 $\lambda$ 使 $\lambda(1,1)^{\mathsf T}=(2,3)^{\mathsf T}$（需要 $\lambda=2$ 又 $\lambda=3$） | 只有**特征空间**（$=\ker(A-\lambda I)$）里的非零向量才是特征向量 |
| 「两个特征向量的和还是特征向量」 | $A=\begin{pmatrix}1&1\\1&1\end{pmatrix}$：$(1,1)^{\mathsf T}$ 是 $\lambda=2$ 的，$(1,-1)^{\mathsf T}$ 是 $\lambda=0$ 的；其和 $(2,0)^{\mathsf T}$：$A(2,0)^{\mathsf T}=(2,2)^{\mathsf T}$，要 $\lambda(2,0)^{\mathsf T}=(2,2)^{\mathsf T}$ 需要 $\lambda=1$ 又 $2=0$，矛盾 | **同一特征值**的特征向量的线性组合才是；不同特征值的不行 |

## F2 通俗理解

**一句人话**：**有些方向，变换只把它们拉长（或压扁、或干脆打成零），不扭转、不转向。**

**类比 · 单杠上的弹簧**：一根弹簧挂在固定方向上，你用力拉 —— 方向不变，长度变了。**弹簧所在的方向就是特征方向，伸长倍数就是特征值。**
不在那个方向上的东西，你一拉它就**歪**（既变长又转向）—— 那不是特征方向。

**类比失效边界（三条）**
- **「不转向」不能推广成「不改变」**：$\lambda=-1$ 时方向完全翻转（$A\mathbf v=-\mathbf v$），$\lambda=0$ 时干脆打成零，**都算「只乘一个数」**。特征的本质是「$A$ 在这个方向上就是乘一个数」，不是「长度不变」。
- **不能把「特征」理解成「最重要」**：它只是「$A$ 表现得最简单」的方向。有些变换在实数范围内**根本没有**特征向量（边界例 3）。
- 类比只帮想到，**不作证明依据**。

**为什么需要它**：特征值把「矩阵」翻译成「一串数」，从此可以谈：矩阵的幂会不会爆炸（$A^n$）、矩阵能否化简（对角化）、系统会不会震荡（振型）。**「这个变换重复做 $n$ 次会怎样」这个问题，只有特征值能回答。**

## F3 严格数学表述

### 定义

设 $T:V\to V$ 线性。若 $\mathbf v\ne\mathbf0$ 且**存在** $\lambda\in\mathbb{F}$ 使 $T\mathbf v=\lambda\mathbf v$，则称 $\mathbf v$ 是 $T$（关于 $\lambda$）的**特征向量**，$\lambda$ 是 **特征值**。

**量词骨架**：**存在** $\lambda$，使 $T\mathbf v=\lambda\mathbf v$ 且 **$\mathbf v\ne\mathbf0$**。两个条件缺一不可。
**$\mathbf v\ne\mathbf0$ 保证 $\lambda$ 唯一**：若 $\mathbf v\ne\mathbf0$ 且 $\lambda_1\mathbf v=\lambda_2\mathbf v$，则 $(\lambda_1-\lambda_2)\mathbf v=\mathbf0$，由 $\mathbf v\ne\mathbf0$ 得 $\lambda_1=\lambda_2$。*依据*：向量空间公理中的非零向量不可消去。

**定义（特征子空间）**：$\mathcal E_\lambda=\{\mathbf v: T\mathbf v=\lambda\mathbf v\}=\ker(T-\lambda I)$。这是**定义等式**（把集合语言换成核），作用是把「找特征向量」变成「解一次齐次方程组」。

### 定义 vs 定理：分界在这张表里

| 说法 | 身份 | 说明 |
|---|---|---|
| $T\mathbf v=\lambda\mathbf v$，$\mathbf v\ne\mathbf0$ | **定义** | 人为约定，不证 |
| 特征值 $=$ $\det(T-\lambda I)$ 的根 | **定理** | 要证（下文给全链） |
| 给定 $\mathbf v\ne\mathbf0$，$\lambda$ 唯一 | **定理** | 一行推导 |
| **特征值与基无关**，特征方向与基无关 | **定理** | 《线性变换与矩阵表示》卡已证 |
| 代数重数 $\ge$ 几何重数 | **定理** | 不可对角化的根源 |
| 不同特征值的特征向量线性无关 | **定理** | 见下 |
| 同一特征值的特征向量的**非零**线性组合仍是该特征值的特征向量 | **定理** | 由线性性直接得 |
| 实对称矩阵特征值为实、特征向量可取成**正交** | **定理（谱定理）** | 见下 |
| $A$ 可对角化 $\iff$ 有 $n$ 个线性无关的特征向量 | **定理** | 本卡的直接后果 |

### 求特征值的唯一完整推导（每步注依据）

$$A\mathbf v=\lambda\mathbf v\iff (A-\lambda I)\mathbf v=\mathbf0\iff \exists\,\mathbf v\ne\mathbf0\ \text{使}\ (A-\lambda I)\mathbf v=\mathbf0\iff A-\lambda I\ \text{奇异}\iff \det(A-\lambda I)=0 .$$

1. **移项**：$A\mathbf v-\lambda\mathbf v=\mathbf0$。*依据*：向量减法定义。
2. **提括号**：$\lambda\mathbf v=\lambda I\mathbf v$ ⟹ $(A-\lambda I)\mathbf v=\mathbf0$。*依据*：数乘与单位矩阵的定义。
3. **读成核**：括号里是齐次方程组，$\exists\mathbf v\ne\mathbf0$ 使它成立。*依据*：$\ker$ 的定义。
4. **用可逆判别**：方阵 $M$ 奇异 $\iff\det M=0$。*依据*：**可逆矩阵的判别定理**。
⟹ **特征值 $=$ 特征多项式 $f(\lambda)=\det(A-\lambda I)$ 的根。**

> ⚠ **最容易写漏的一步是第 2 步里的 $I$**。写成 $A-\lambda$（把**每个元素**都减 $\lambda$）就全错：
> - $A=\begin{pmatrix}2&0\\0&3\end{pmatrix}$ 时，$A-\lambda J=\begin{pmatrix}2-\lambda&-\lambda\\-\lambda&3-\lambda\end{pmatrix}$ 的行列式 $=(2-\lambda)(3-\lambda)-\lambda^2=6-5\lambda$，得「特征值」 $\lambda=1.2$ —— 而真特征值是 $2$ 与 $3$ ✗
> - $A=\begin{pmatrix}2&1\\1&1.5\end{pmatrix}$ 时，$\det(A-\lambda J)=(2-\lambda)(1.5-\lambda)-(1-\lambda)^2=2-1.5\lambda$，得 $\lambda=\tfrac43\approx1.333$ —— 而真特征值是 $0.719224$ 与 $2.78078$ ✗

### 定理：不同特征值的特征向量线性无关（带读证明）

**定理**：若 $\lambda_1,\dots,\lambda_k$ **互不相同**，$\mathbf v_i\ne\mathbf0$ 且 $A\mathbf v_i=\lambda_i\mathbf v_i$，则 $\mathbf v_1,\dots,\mathbf v_k$ 线性无关。

**证明（归纳法，请照这个版本练）**
1. **$k=1$**：单个非零向量必然无关（否则 $c_1\mathbf v_1=\mathbf0$ 迫使 $c_1=0$，与「非平凡相关」矛盾）。*依据*：$\mathbf v_1\ne\mathbf0$。
2. **归纳假设**：设 $\mathbf v_1,\dots,\mathbf v_{k-1}$ 已线性无关。
3. **假设前 $k$ 个相关** ⟹ 存在不全为零的 $c_1,\dots,c_{k-1}$ 使 $\mathbf v_k=\sum_{i<k}c_i\mathbf v_i$。*依据*：相关的定义（$\mathbf v_k$ 的系数可归一为 $1$）。
4. 两边作用 $A$：$\lambda_k\mathbf v_k=A\mathbf v_k=\sum_{i<k}c_i\lambda_i\mathbf v_i$。
5. 代入第 3 步：$\lambda_k\sum_{i<k}c_i\mathbf v_i=\sum_{i<k}c_i\lambda_i\mathbf v_i$ ⟹ $\sum_{i<k}c_i(\lambda_k-\lambda_i)\mathbf v_i=\mathbf0$。*依据*：移到同侧合并同类项。
6. 因归纳假设，这组向量无关，故每个系数都必须为零；又 $\lambda_k-\lambda_i\ne0$（$\lambda_i$ **互不相同**），于是 $c_i=0$ 对一切 $i<k$。
7. 于是 $\mathbf v_k=\mathbf0$，与假设 $\mathbf v_k\ne\mathbf0$ **矛盾**。$\blacksquare$

> **关键在第 6 步用了两件东西**：归纳假设（无关 ⟹ 系数全零）与 $\lambda_k\ne\lambda_i$（把 $c_i$ 逐个救出来）。缺任何一个都推不下去。

### 定理：实对称矩阵不同特征值的特征向量正交（带读证明）

**定理**：$A$ 实对称（$A^{\mathsf T}=A$），$A\mathbf v=\lambda\mathbf v$、$A\mathbf w=\mu\mathbf w$、$\lambda\ne\mu$ ⟹ $\langle\mathbf v,\mathbf w\rangle=0$。

**证明**：
$$\lambda\langle\mathbf v,\mathbf w\rangle=\langle A\mathbf v,\mathbf w\rangle=\langle\mathbf v,A^{\mathsf T}\mathbf w\rangle=\langle\mathbf v,A\mathbf w\rangle=\mu\langle\mathbf v,\mathbf w\rangle .$$
⟹ $(\lambda-\mu)\langle\mathbf v,\mathbf w\rangle=0$ ⟹ $\langle\mathbf v,\mathbf w\rangle=0$。*依据*：中间那一步用到 $\langle Au,v\rangle=\langle u,A^{\mathsf T}v\rangle$（**伴随算子的对称性定理**）与 $A^{\mathsf T}=A$。$\blacksquare$

**数值验证**：$A=\begin{pmatrix}1&1\\1&1\end{pmatrix}$ 的 $\lambda=2$ 特征向量 $(1,1)^{\mathsf T}$ 与 $\lambda=0$ 的 $(1,-1)^{\mathsf T}$：$(1,1)\cdot(1,-1)=1-1=0$ ✓

### 删条件实验 ⭐

| 删掉 / 改动 | 后果 | 验算 |
|---|---|---|
| 定义里的 $\mathbf v\ne\mathbf0$ | $\mathbf0$ 对任何 $\lambda$ 都满足 ⟹ **特征值 $=$ 全体数** | $A=\begin{pmatrix}2&0\\0&3\end{pmatrix}$：$\mathbf0$ 使 $\lambda=5$、$\lambda=\pi$ 全都「成立」 |
| 把 $\lambda$ 从「复数」限定成「实数」 | 有些变换「没有特征向量」 | $A=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$：$\lambda^2+1=0$ 无实根；它明明是标准的旋转 |
| 「给定 $\mathbf v$ 则 $\lambda$ 唯一」的前提删掉 | 谈不了「这个 $\lambda$」 | $\mathbf v=\mathbf0$ 时 $\lambda_1\mathbf0=\lambda_2\mathbf0=\mathbf0$ 对一切 $\lambda$ ⟹ 不唯一 |
| $\det(A-\lambda I)$ 里的 $I$ 漏掉（写成 $A-\lambda$） | 算出与 $\lambda$ 纠缠的错误多项式 | $A=\begin{pmatrix}2&0\\0&3\end{pmatrix}$：$\det(A-\lambda J)=6-5\lambda$ ⟹ 根 $1.2$，真特征值是 $2,3$ ✗ |
| 「任意特征向量的线性组合仍是特征向量」 | 立刻出反例 | $A=\begin{pmatrix}1&1\\1&1\end{pmatrix}$：$(1,1)^{\mathsf T}+(1,-1)^{\mathsf T}=(2,0)^{\mathsf T}$，而 $A(2,0)^{\mathsf T}=(2,2)^{\mathsf T}\ne\lambda(2,0)^{\mathsf T}$ |

### 操作骨架：怎么求（2 阶全流程）

① **写 $f(\lambda)=\det(A-\lambda I)$**（2 阶：$(a-\lambda)(d-\lambda)-bc=\lambda^2-(a+d)\lambda+(ad-bc)$）→ ② **解 $f(\lambda)=0$** 得**全部**特征值 → ③ **对每个 $\lambda_i$ 解齐次方程组** $(A-\lambda_i I)\mathbf x=\mathbf0$，基础解系就是该特征值的一组特征向量 → ④ **数一数**独立方向，与 $f$ 的根的重数比一比 → ⑤ 判断可对角化。

**顺带的两个快算（自己证，别背）**：
- **特征向量的坐标公式**：由 $(a-\lambda)x+by=0$ 得 $\boxed{y=\frac{\lambda-a}{b}\,x}$（$b\ne0$ 时），取 $x=1$ 即得。
  验算：$A=\begin{pmatrix}2&0.75\\-0.75&0.5\end{pmatrix}$、$\lambda=1.25$：$y=\frac{1.25-2}{0.75}x=-x$ ⟹ $\mathbf v=(1,-1)^{\mathsf T}$；归一化 $\tfrac{1}{\sqrt2}(1,-1)\approx(0.7071,-0.7071)^{\mathsf T}$，算 $A\mathbf v=(0.883883,-0.883883)^{\mathsf T}=1.25\,\mathbf v$ ✓
  （⚠ 这里的 $b$ 是**分母**：$b=1$ 的例子最省事，容易让人忘字。）
- **迹与行列式**：$\sum\lambda_i=\operatorname{tr}A$，$\prod\lambda_i=\det A$（含重数）。
  验算：$A=\begin{pmatrix}2&1\\1&1.5\end{pmatrix}$：$2.78078+0.719224=3.5=\operatorname{tr}A$ ✓；$2.78078\times0.719224\approx2=\det A$ ✓

## F4 几何 / 物理意义

- **「不变的方向」**：特征向量所在的方向在变换下**不变**（只是长度与朝向按 $\lambda$ 变）。这是「$A$ 表现得最简单」的方向。
- **$\det(A-\lambda I)=0$ 的几何含义（最有力的一句）**：$A-\lambda I$ 把整个空间**压扁了**（奇异 ⟹ 存在非零方向被压成 $\mathbf0$）—— **那个被压扁的方向，就是 $A$ 的特征向量**。特征值是「在压扁之前先减掉多少」。
- **平面上的完整画面**：$A=\begin{pmatrix}a&b\\c&d\end{pmatrix}$ 的特征值是 $f(\lambda)=\lambda^2-(a+d)\lambda+(ad-bc)$ 的根；判别式 $(a-d)^2+4bc$ 决定「有两条不变方向 / 一条 / 是复数（没有实不变方向）」。
  验算：$a=2,b=1,c=1,d=1.5$ ⟹ 判别式 $=(0.5)^2+4=4.25>0$ ⟹ 两个实特征值 ✓（实算得 $0.719224,\ 2.78078$ ✓）；$a=d=0,\ b=1,\ c=-1$（即旋转 $90^\circ$ 的另一种写法）⟹ 判别式 $=0-4=-4<0$ ⟹ 无实特征向量 ✓。
- **回指 F3**：换基后的矩阵仍是「上块 + 下零」形状，但**那个上块 $A$ 的特征值就是原 $T$ 的特征值**（《线性变换与矩阵表示》卡已证「特征值与基无关」）—— 几何上就是「不变的方向」本身不随坐标变。
- **物理类比 · 振型（normal mode）**：一个机械系统或电路里「只振动、不绕圈」的那些固有频率与形状，就是它的特征值与特征向量。**这正是钢琴按一个键就能让某些弦共振、而其他弦不响的原因。**

## 🧮 概念计算器（输入 → 输出）

特征值与几何重数手算极易错（尤其是重复特征值），所以给它一个函数：输入 $2\times2$ 矩阵，输出特征值与每个特征值的几何重数。

```calc
# PYTHON
import numpy as np
def spec(A):
    A = np.array(A, dtype=float)
    tr, det = A.trace(), np.linalg.det(A)
    lam = np.roots([1, -tr, det])
    lam = np.where(np.abs(lam.imag) < 1e-9, lam.real, lam)
    lam = np.array(sorted(lam, key=lambda z: (z.real, z.imag)))
    parts = []
    for z in lam:
        if abs(z.imag) < 1e-9:
            M = A - z.real * np.eye(2)
            M = np.where(np.abs(M) < 1e-9, 0, M)
            parts.append(f"{z.real:g}(几何重数{2 - np.linalg.matrix_rank(M)})")
        else:
            parts.append(f"{z.real:g}{z.imag:+.4g}j(实数范围内无特征向量)")
    return f"特征值 = [{', '.join(parts)}]  迹 = {tr:g}  行列式 = {det:g}"
for A in ([[2,0],[0,1.5]], [[2,1],[1,1.5]], [[1,1],[0,1]], [[0,-1],[1,0]], [[2,0.75],[-0.75,0.5]]):
    print(spec(A))
# 预期输出:
# 特征值 = [1.5(几何重数1), 2(几何重数1)]  迹 = 3.5  行列式 = 3
# 特征值 = [0.719224(几何重数1), 2.78078(几何重数1)]  迹 = 3.5  行列式 = 2
# 特征值 = [1(几何重数1), 1(几何重数1)]  迹 = 2  行列式 = 1
# 特征值 = [0-1j(实数范围内无特征向量), 0+1j(实数范围内无特征向量)]  迹 = 0  行列式 = 1
# 特征值 = [1.25(几何重数1), 1.25(几何重数1)]  迹 = 2.5  行列式 = 1.5625
# R
spec = \(A) {
  A = matrix(as.numeric(A), nrow = 2, byrow = TRUE)
  tr = sum(diag(A)); det = det(A); disc = tr^2 - 4 * det
  roots = if (disc >= -1e-12) sort(c((tr + sqrt(max(disc, 0)))/2, (tr - sqrt(max(disc, 0)))/2))
          else complex(real = tr/2, imaginary = c(-sqrt(-disc)/2, sqrt(-disc)/2))
  parts = vapply(roots, \(z) if (abs(Im(z)) < 1e-9) {
    M = A - Re(z) * diag(2); M[abs(M) < 1e-9] = 0
    paste0(sprintf("%.6g", Re(z)), "(几何重数", 2 - qr(M)$rank, ")")
  } else paste0(sprintf("%.6g", Re(z)), sprintf("%+.4gj", Im(z)), "(实数范围内无特征向量)"), character(1))
  cat(paste0("特征值 = [", paste(parts, collapse = ", "), "]  迹 = ", tr, " 行列式 = ", det, "\n"), sep = "")
}
for (M in list(c(2, 0, 0, 1.5), c(2, 1, 1, 1.5), c(1, 1, 0, 1), c(0, -1, 1, 0), c(2, 0.75, -0.75, 0.5))) spec(M)
# 预期输出:
# 特征值 = [1.5(几何重数1), 2(几何重数1)]  迹 = 3.5  行列式 = 3
# 特征值 = [0.719224(几何重数1), 2.78078(几何重数1)]  迹 = 3.5  行列式 = 2
# 特征值 = [1(几何重数1), 1(几何重数1)]  迹 = 2  行列式 = 1
# 特征值 = [0-1j(实数范围内无特征向量), 0+1j(实数范围内无特征向量)]  迹 = 0  行列式 = 1
# 特征值 = [1.25(几何重数1), 1.25(几何重数1)]  迹 = 2.5  行列式 = 1.5625
```

> **读法**：**代数重数 $=$ 你数出几项**（重复的 $\lambda$ 写几次就是几重）；**几何重数 $=$ 每项后面那个括号**。第一行 $\lambda$ 各出现一次 ⟹ 两个 $1$；第三、五行 $\lambda$ 出现两次但几何重数都是 $1$ ⟹ **代数 $> $ 几何**，正是边界例 2 与第 3 站那种情形。
> ⚠ **三个真实踩过的坑**（都写在这段代码里）：
> ① **重复特征值在浮点下会「变虚」**：`np.linalg.eig` 对 $\lambda=1.25$ 的重根返回 $1.25\pm1.29\times10^{-8}i$，直接打印会以为「重根变成了复根」，判独立个数也会误判成 $2$。所以代码**从特征多项式求根**并**抹掉虚部噪声**。
> ② **判秩必须用容差**：精确等于 $0$ 的判定在数值上没有意义，代码里用 $10^{-9}$。
> ③ **特征向量公式里 $b$ 是分母**：$y=\frac{\lambda-a}{b}x$，不是 $\lambda-a$。我第一次就写错了，导致算出 $(0.8,-0.6)$ 这种「看着像、其实不是特征向量」的结果。

## 说到「特征值与特征向量」，你要想到……（闭卷 60 秒，≥4 条才算过）

1. **定义两个条件缺一不可**：$\mathbf v\ne\mathbf0$ 且存在 $\lambda$；**$\lambda$ 可以是 $0$，$\mathbf v$ 不能是 $\mathbf0$**。
2. **求法只有一条链**：$A\mathbf v=\lambda\mathbf v\iff\det(A-\lambda I)=0$ ⟹ 每个根再解一次齐次方程组。
3. **特征值不是对角元**！只有上／下**三角**矩阵才是。
4. $\lambda$ **可以是复数**（实矩阵也可能有复特征值）；实对称矩阵则一定全为实。
5. **代数重数 $\ge$ 几何重数**；不等 ⟹ 不可对角化。
6. **同一特征值**的特征向量的线性组合仍是特征向量；**不同特征值的不行**。
7. **不同特征值的特征向量线性无关**（证法：归纳 + 错位对比）。
8. **实对称 ⟹ 特征向量可取成正交**（谱定理）。
9. **特征值与基无关** ⟹ 它是**变换的属性**，不是矩阵的属性。

## 常见错位清单（〔〕内是**错误来源**）

1. 〔**定理当定义**〕以为「特征值 $=$ 对角元」——只有**三角**矩阵才成立。
2. 〔**字眼漏读**〕漏掉 $\mathbf v\ne\mathbf0$，于是 $\mathbf0$ 把一切 $\lambda$ 都「成就」了。
3. 〔**字眼漏读**〕以为 $\lambda$ 必须非零 —— $\lambda=0$ **可以是**特征值（当 $A$ 奇异时）。
4. 〔**类比越界**〕把「特征」理解成「最重要」，或以为每个变换都有实特征向量。
5. 〔**定理当定义**〕把「代数重数 $\ge$ 几何重数」当定义；或由「特征值有 $n$ 个（含重数）」直接推出可对角化。
6. 〔**记号混用 / 量词顺序**〕以为不同特征值的特征向量之和仍是特征向量。
7. 〔**字眼漏读**〕$f(\lambda)=\det(A-\lambda I)$ 里的 $I$ 漏掉，写成 $\det(A-\lambda)$。
8. 〔**计算陷阱**〕特征向量公式里 $b$ 是**分母**：$y=\frac{\lambda-a}{b}x$。
