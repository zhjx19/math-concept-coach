F2 通俗理解

一句人话：你开了一趟车，全程平均时速 60 km/h。中值定理说：路上一定有某个瞬间，时速表正好指着 60。

类比 · 三个说法

说法 中值定理的 ξ\xi 是什么
物理 速度等于平均速度的那一刻
几何 切线平行于割线的那个点
分析 使 f′(ξ)−k=0f'(\xi)-k=0 的那个点

失效边界（四条）

  • 「一定有」不等于「只有一处」 —— 边界例 1：x3x^3 在 [−1,1][-1,1] 上有两个这样的瞬间；
  • 「一定有」也不等于「找得到」 —— 方程 f′(ξ)=kf'(\xi)=k 往往解不出根。定理负责「有」，不负责「算出」；
  • 速度表会坏 —— 边界例 2：|x||x| 在 00 的「时速表指针」在 ±1\pm1 之间猛跳（不可导），于是「存在某一瞬间正好等于平均值 00」这句话失效；
  • 终点可以是被篡改的 —— 边界例 2：f(1)f(1) 被单独改成 55 而左边极限是 11，平均速度就成了 55——但车上从没开过 55。连续性假设就是防这个的。

为什么需要它：上一张卡说「导数只管一个点」。光靠「每一点有导数」，你无法推出任何关于整个区间的结论 —— 函数可能在区间里上蹿下跳。要说「这辆车总体在加速」，就必须有一条定理把点连成区间。单调性、极值、不等式证明、微分方程的存在性，全都从这一条来。

F3 严格数学表述（分档：低档 → 中档 → 高档）

🟢 低档（默认必给）：先不碰符号

「中值定理」在说什么 —— 一句大白话 + 一个具体例子：

从 aa 走到 bb，全程的平均速度是「总路程 ÷ 总时间」。 中值定理说：路上一定有那么一瞬间，速度恰好等于这个平均速度。

例：f(x)=x2f(x)=x^2，从 00 走到 11。总路程 =1=1，总时间 =1=1，平均速度 =1=1。 出发那一瞬间速度是 00（f′(0)=0f'(0)=0），到终点前那一瞬间速度是 22（f′(1)=2f'(1)=2）。 速度从 00 慢慢爬到 22，中间一定经过 11 —— 而且恰好在 x=0.5x=0.5 时经过。 那 0.50.5 就是 ξ\xi。

「罗尔定理」在说什么 —— 还是大白话：

如果起点和终点「一样高」，那路上一定有一处是平的（速度为零）。

例：你骑车上山，起点和终点海拔相同。中途一定有某一瞬间，你的垂直速度是 00 —— 那就是山顶（或山坳）。 f=x2f=x^2 在 [0,1][0,1] 上 f(0)=f(1)=0f(0)=f(1)=0，所以一定有点 f′(ξ)=0f'(\xi)=0（确实是 0.50.5）。 |x|\lvert x\rvert 在 [−1,1][-1,1] 上 f(−1)=f(1)=1f(-1)=f(1)=1，也想让你相信「有点 f′(ξ)=0f'(\xi)=0」 —— 但它的「时速表」在 00 处坏了（不可导），在 −1-1 那边一直 −1-1、在 +1+1 那边一直 +1+1，就是从来没到过 00。这就是「可导」假设不能去掉的道理。

🔵 中档：定义原文 + 量词骨架 + 逐词翻译

定理一（罗尔，Rolle）

设 ff 在 [a,b][a,b] 上连续、在 (a,b)(a,b) 内可导，且 f(a)=f(b)f(a)=f(b)，则 ∃ξ∈(a,b)\exists\,\xi\in(a,b) 使 f′(ξ)=0f'(\xi)=0。

定理二（拉格朗日中值，拉氏）

设 ff 在 [a,b][a,b] 上连续、在 (a,b)(a,b) 内可导，a<ba<b，则 ∃ξ∈(a,b)\exists\,\xi\in(a,b) 使 f′(ξ)=f(b)−f(a)b−af'(\xi)=\frac{f(b)-f(a)}{b-a}

定理三（柯西中值，Cauchy）

设 f,gf,g 都在 [a,b][a,b] 上连续、(a,b)(a,b) 内可导，g′≠0g'\ne0，则 ∃ξ∈(a,b)\exists\,\xi\in(a,b) 使 (f(b)−f(a))g′(ξ)=(g(b)−g(a))f′(ξ)\bigl(f(b)-f(a)\bigr)g'(\xi)=\bigl(g(b)-g(a)\bigr)f'(\xi)

逐词翻译（三个假设的位置最关键）：

假设 字面 管的是哪一段 为什么不能用别的段替代
ff 在 [a,b][a,b] 上连续 含两端 端点值 f(a),f(b)f(a),f(b) 端点值进公式；端点跳了，平均速度就是假的（边界例 2）
ff 在 (a,b)(a,b) 内可导 不含两端 区间内部每一点的斜率 ξ\xi 在开区间内；端点可导与否不影响结论（例如 f=xf=\sqrt x 在 [0,1][0,1] 上：f′(0)f'(0) 不存在，但定理照样成立）
a<ba<b 非退化 割线斜率有定义 a=ba=b ⟹ 00\frac00

⭐⭐ 「连续用闭区间、可导用开区间」不是随便写的。 这是本卡最容易考的一条措辞题： 闭区间上的连续 ⟹ 端点极限等于端点值；而开区间上的可导根本不约束端点。 记忆法：连续是「整体性质」所以要含端；可导是「局部性质」所以用开区间。

三条定理的关系（不是三个孤立结论）：

拉格朗日=罗尔 作用在 F(x)=f(x)−[f(a)+f(b)−f(a)b−a(x−a)] 上\boxed{\text{拉格朗日} = \text{罗尔} \text{ 作用在 } F(x)=f(x)-\bigl[f(a)+\tfrac{f(b)-f(a)}{b-a}(x-a)\bigr]\text{ 上}} 柯西=拉格朗日 对 F(x)=f(x)−λg(x) 取合适的 λ\boxed{\text{柯西} = \text{拉格朗日} \text{ 对 } F(x)=f(x)-\lambda\,g(x)\text{ 取合适的 }\lambda}

推论一（严格单调）

f′在 (a,b)内处处>0⇒∀x1<x2:f(x1)<f(x2)f'\ \text{在 }(a,b)\ \text{内处处}>0\ \Longrightarrow\ \forall\,x_1<x_2:\ f(x_1)<f(x_2)

证明一行：f(x2)−f(x1)=f′(ξ)(x2−x1)\displaystyle f(x_2)-f(x_1)=f'(\xi)(x_2-x_1)，而 f′(ξ)>0f'(\xi)>0、x2−x1>0x_2-x_1>0 ⟹ 乘积 >0>0。

推论二（不等式证明的标准套路）

f′在 (a,b)内处处>g′⇒h=f−g在 [a,b]严格递增f'\ \text{在 }(a,b)\ \text{内处处}>g'\ \Longrightarrow\ h=f-g\ \text{在 }[a,b]\ \text{严格递增}

⟹ 证明不等式的老办法：造一个差，让它的导数定号。 这是后面凹凸性、最优化、以及 ex>xe^x>x 这类经典不等式的统一打法。

🟣 高档（你追问「为什么」时再看）

  • 罗尔定理本身不能由柯西直接「退化」得到 —— 令 g(x)=xg(x)=x 就得到拉格朗日；但要得到罗尔需再令 f(a)=f(b)f(a)=f(b)。顺序是「柯西 ⊃ 拉格朗日 ⊃ 罗尔」；
  • Darboux 定理（边界例 6）：ff 可导 ⟹ f′f' 取遍中间值，不需要 f′f' 连续。证明要用极值定理或辅助函数，不是罗尔的直接推论（更后面的工具）；
  • 洛必达的证明骨架（边界例 5）：柯西 ⟹ 差商 =f′(ξ)/g′(ξ)=f'(\xi)/g'(\xi)，ξ∈(0,x)\xi\in(0,x) ⟹ x→0x\to0 时 ξ→0\xi\to0 ⟹ lim⁡fg=lim⁡f′g′\lim\dfrac fg=\lim\dfrac{f'}{g'}。注意这需要 f′f'、g′g' 的极限都存在 —— 这就是《极限》边界例 4 强调「商的极限存在」那个前提的来源（更后面的工具）；
  • 积分中值定理与拉格朗日平行：∫abf=f(ξ)(b−a)\int_a^b f = f(\xi)(b-a)。证明手法一模一样（凑辅助函数）；

import numpy as np
def xi_of(kind, a, b, t):
    if kind == 1:      # f=x^2 : k = a+b, 2*xi = k
        k = (b * b - a * a) / (b - a)
        xs = [k / 2.0]
        tags = ["f'=2x"]
    elif kind == 2:    # f=x^3 : k = a^2+ab+b^2, 3*xi^2 = k
        k = (b ** 3 - a ** 3) / (b - a)
        r = (k / (3.0 * b * b)) ** 0.5
        xs = [r, -r]
        tags = ["3x^2=k (+)", "3x^2=k (-)"]
    else:              # f=ln x
        k = (np.log(b) - np.log(a)) / (b - a)
        xs = [1.0 / k]
        tags = ["f'=1/x"]
    s = "; ".join("%s ξ=%+.15f" % (tag, v) for v, tag in zip(xs, tags))
    return "f%d on [%+.6f,%+.6f] : 割线斜率 k = %+.15f ; 解数=%d ; %s" % (kind, a, b, k, len(xs), s)
def slope_in_range(a, b, c_lo, c_hi, k):
    return ("区间 [%+.2f,%+.2f] : 割线斜率 k = %+.12f ; f' 值域 [%+.6f, %+.6f] ; k 在值域内? %s"
            % (a, b, k, c_lo, c_hi, "是(有解)" if c_lo <= k <= c_hi else "否(无解)"))
def aux_F(x, a, b, k):
    f = x * x
    F = f - (a * a + k * (x - a))
    return "x=%+.2f : f=%.10f  F(x)=%+.12f  F'(x)=%+.12f" % (x, f, F, 2 * x - k)
def cauchy_exact(x):
    q = (np.exp(x) - 1) / x
    xi = np.log(q)
    lhs = np.exp(x) - 1
    rhs = x * np.exp(xi)
    return ("x=%.4f : 差商=%.15f  ξ=%.15f  ξ∈(0,x)? %s ; 左右边相等? %s ; ξ/x=%.15f"
            % (x, q, xi, "是" if 0 < xi < x else "否",
               "是" if abs(lhs - rhs) < 1e-12 else "否", xi / x))
def darboux_probe(k):
    x = 1.0 / (2 * k * np.pi)
    y = 1.0 / ((2 * k + 1) * np.pi)
    fpx = 2 * x * np.sin(1 / x) - np.cos(1 / x)
    fpy = 2 * y * np.sin(1 / y) - np.cos(1 / y)
    return ("k=%d : x=%.15f f'=%+.15f | y=%.15f f'=%+.15f | 同时取到 ±1? %s"
            % (k, x, fpx, y, fpy, "是" if abs(fpx + 1) < 1e-12 and abs(fpy - 1) < 1e-12 else "否"))
def rolle_probe(x):
    fp = -1.0 if x < 0 else (1.0 if x > 0 else float("nan"))
    return "f=|x| : x=%+.1e  f'(x) = %s" % (x, "不存在" if np.isnan(fp) else "%+.6f" % fp)
def cont_probe(x):

  if (kind == 1) {
    k = (b^2 - a^2)/(b - a); xs = c(k/2); tags = c("f'=2x")
  } else if (kind == 2) {
    k = (b^3 - a^3)/(b - a); r = (k/(3*b^2))^0.5
    xs = c(r, -r); tags = c("3x^2=k (+)", "3x^2=k (-)")

  sprintf("f%d on [%+.6f,%+.6f] : 割线斜率 k = %+.15f ; 解数=%d ; %s",

slope_in_range = \(a, b, c_lo, c_hi, k) {

cauchy_exact = \(x) {
  q = (exp(x) - 1)/x
  xi = log(q)
  sprintf("x=%.4f : 差商=%.15f  ξ=%.15f  ξ∈(0,x)? %s ; 左右边相等? %s ; ξ/x=%.15f",

darboux_probe = \(k) {

}

常见错位清单（〔〕内是错误来源）

  1. 〔假设写错区间〕 把「[a,b][a,b] 连续、(a,b)(a,b) 可导」写成两个都用 [a,b][a,b] 或都用 (a,b)(a,b)。连续含端、可导不含端。（F3 逐词翻译）
  2. 〔存在当恒等〕 从 f(a)=f(b)f(a)=f(b) 推出 f′≡0f'\equiv0。罗尔只保证「至少一个零点」。
  3. 〔拿定理当求解〕 试图用中值定理算出 ξ\xi。它是存在性定理，且不保证唯一。（边界例 1）
  4. 〔倒用逆否〕 以为「可导 ⟹ 连续」是双向的。「f′f' 值域装不下 kk」就无解，而 kk 由端点值决定 ⟹ 端点跳了结论就崩。（边界例 2）
  5. 〔漏掉辅助函数〕 证明时直接对 ff 用罗尔。必须先减去割线直线，否则两端不同值。（边界例 3）
  6. 〔单调性用词〕 f′≥0f'\ge0 只能说「单调不减」。要「严格递增」需 f′>0f'>0 在开区间处处（f′f' 在开区间内个别点为 00 仍可严格递增，如 x3x^3 在 ℝ\mathbb R）。（边界例 4）
  7. 〔误以为导数连续〕 用「导函数连续 ⟹ 有介值性」去解释 f′f'。导函数可以不连续（f=x2sin⁡1xf=x^2\sin\frac1x），介值性来自 Darboux 定理。（边界例 6）
