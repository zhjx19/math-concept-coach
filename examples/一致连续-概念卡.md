# 一致连续

> 📌 所属：数学分析 · 函数连续性 ｜ 教材出处：以你所用教材对应章节为准（华东师大版可查"函数的一致连续性"一节）
> 🎯 学完你应该能：写出定义、说出它与「连续」的唯一差别、举出反例、判断给定的函数是否一致连续。
> 💡 **一句话钩子**：同一个 δ 要能管住整条区间，不能每换一个点就换一把尺子。
> 🧱 **假设基底（待你确认）**：我猜你已经会「极限、连续」——**你觉得自己会吗？** → 缺「δ 能不能与点的位置无关」→ 本概念补上这一步。

## F1 正反拆解

| 类别 | 例子 | 说明 |
|---|---|---|
| 正例 | $f(x)=x$、$f(x)=\sin x$ 在 $\mathbb{R}$ 上 | 整条实轴共用一个 δ |
| 正例 | $f(x)=\sqrt{x}$ 在 $[1,+\infty)$ 上 | 变化率有界 |
| **边界例** | $f(x)=x^2$：在 $[0,1]$ 上**一致连续**，在 $\mathbb{R}$ 上**不一致连续** | 同一函数，换个定义域结论就反了 |
| **反例** | $f(x)=\dfrac{1}{x}$ 在 $(0,1)$ 上连续但**不一致连续** | 越靠近 0，需要越小的 δ |

## F2 通俗理解

- **一句人话**：「整段曲线能**共用一套宽容标准**：无论你站在哪一段，我都能用**同一个 δ**，保证函数值的变化小于你给的 ε。」
- **类比**：像一把**刻度固定的尺子**量整条曲线。连续的函数每一点都能量，但可以一点换一把尺；一致连续要求**换点不换尺**。
- **类比失效的边界**：别说「一致连续就是更连续」——**连续不分强弱**。差别**只在 δ 是否依赖位置**，不在「更/更不」。
- **为什么要它**：它把「逐点的局部性质」升级为「整体性质」，是「闭区间上连续函数可积」以及极限与积分可交换这类定理的落脚点。

## F3 严格数学表述

**定义**：设 $f$ 在区间 $I$ 上有定义。
$$f \text{ 在 } I \text{ 上一致连续} \iff \forall \varepsilon>0,\ \exists \delta>0,\ \forall x_1,x_2\in I,\ \lvert x_1-x_2\rvert<\delta \implies \lvert f(x_1)-f(x_2)\rvert<\varepsilon.$$

**对照「连续」（逐点）**：
$$\forall x_0\in I,\ \forall \varepsilon>0,\ \exists \delta>0,\ \forall x\in I,\ \lvert x-x_0\rvert<\delta \implies \lvert f(x)-f(x_0)\rvert<\varepsilon.$$

| 项目 | 一致连续 | 连续（逐点） |
|---|---|---|
| 量词骨架 | $\forall\varepsilon\,\exists\delta\,\forall x_1\,\forall x_2$ | $\forall x_0\,\forall\varepsilon\,\exists\delta\,\forall x$ |
| δ 可以依赖谁 | **只依赖 ε** | 依赖 ε **和 $x_0$** |
| 身份 | **定义**（人为规定，不要去证它） | **定义** |

> **核心一句话**：δ 出现在 $x_1,x_2$ **之前**还是**之后**，就是本质区别。

**否定式**（用来证明「不一致连续」）：
$$\exists \varepsilon>0,\ \forall \delta>0,\ \exists x_1,x_2\in I,\ \lvert x_1-x_2\rvert<\delta\ \wedge\ \lvert f(x_1)-f(x_2)\rvert\ge\varepsilon.$$

**删条件实验**：把定义里的「$\forall x_1,x_2\in I,\ \lvert x_1-x_2\rvert<\delta$」改成「固定 $x_0$，$\lvert x-x_0\rvert<\delta$」——
量词一改，概念立刻**退化为连续**。这就是两者的**全部差别**。

**操作骨架（怎么证一致连续）**：① 任给 $\varepsilon>0$ → ② 找一个**不依赖位置**的 $\delta(\varepsilon)$
（常用 Lipschitz 估计 $\lvert f(x_1)-f(x_2)\rvert\le L\lvert x_1-x_2\rvert$，或中值定理）→ ③ 取 $\delta$ 使 $L\delta\le \varepsilon$ → ④ 验证。

## F4 几何意义

把曲线放进一个「**横向 ε 带、纵向 δ 带**」的矩形窗口里：

- **连续**：在**每一个位置**，都能找到某个 δ 窗口把曲线框住；
- **一致连续**：全区间能用**同一个宽度**的 δ 窗口框住。

曲线越陡，需要的 δ 越小。一致连续 = 陡峭程度**整体上被控制住**，没有一处可以任意陡。$1/x$ 在 0 附近越来越陡，于是失守。

**回指式子**：这个「同一个 δ」正是 F3 里 $\exists\delta$ 出现在 $\forall x_1,x_2$ **之前**的几何含义。

## 🧮 概念计算器（输入 → 输出）

一致连续的关键是「**δ 能不能只由 ε 决定、与点在哪儿无关**」。这个计算器对 $f(x)=x^2$ 在
$[0,b]$ 上给出一个**只用 $\varepsilon$ 与区间端点 $b$** 的 $\delta$：
由 $\lvert x^2-y^2\rvert=\lvert x+y\rvert\,\lvert x-y\rvert\le 2b\,\lvert x-y\rvert<\varepsilon$，取 $\delta=\dfrac{\varepsilon}{2b}$ 即可。

```calc
# PYTHON
def delta_for_x2(eps, b):     # f(x)=x^2 在 [0,b] 上：取 delta = eps/(2b)
    return eps / (2 * b)
for eps in (0.1, 0.01):
    print(f"eps={eps:<5} b=1 -> delta={delta_for_x2(eps, 1):.4f}   b=10 -> delta={delta_for_x2(eps, 10):.4f}")
# 预期输出:
# eps=0.1   b=1 -> delta=0.0500   b=10 -> delta=0.0050
# eps=0.01  b=1 -> delta=0.0050   b=10 -> delta=0.0005
# R
delta_for_x2 = \(eps, b) eps / (2 * b)
for (eps in c(0.1, 0.01)) cat(sprintf("eps=%-5g b=1 -> delta=%.4f   b=10 -> delta=%.4f\n", eps, delta_for_x2(eps, 1), delta_for_x2(eps, 10)))
# 预期输出:
# eps=0.1   b=1 -> delta=0.0500   b=10 -> delta=0.0050
# eps=0.01  b=1 -> delta=0.0050   b=10 -> delta=0.0005
```

> **读法**：同一个 $\varepsilon$ 下，区间越长（$b$ 越大）$\delta$ 必须越小；但**只要 $b$ 固定**，
> 这个 $\delta$ 就能管住整条区间，与 $x_0$ 落在哪里无关——这正是「一致」。
> 换成 $(0,1]$ 上的 $f(x)=\dfrac1x$，就**找不到**只依赖 $\varepsilon$ 的 $\delta$（F1 的反例）。

## 说到「一致连续」，你要想到……（闭卷能一口气说出 ≥4 条才算过）

1. **定义**：$\forall\varepsilon>0\ \exists\delta>0\ \forall x_1,x_2\in I,\ \lvert x_1-x_2\rvert<\delta\Rightarrow\lvert f(x_1)-f(x_2)\rvert<\varepsilon$——**δ 出现在 $x_1,x_2$ 之前**；
2. 与**连续**的唯一差别：δ 是否依赖位置（就是量词顺序之差）；
3. **几何**：整段曲线共用**同一个宽度的 δ 盒子**；
4. **定理**（不是定义）：闭区间上连续 $\Rightarrow$ 一致连续（Cantor 定理）；
5. **判别路径**：端点、陡峭度——Lipschitz 连续或导数有界是**充分条件**；
6. **反例**：$\dfrac1x$ 在 $(0,1)$ 上、$x^2$ 在 $\mathbb{R}$ 上。

## 自检：你学会了吗？（先自己想，再看答案 ↓）

1. 判断真假并说明依据：「$f$ 在 $(0,1)$ 上连续，则 $f$ 在 $(0,1)$ 上一致连续。」
2. 举一个反例：一个在某个区间上连续但不一致连续的函数。（提示：让它越靠近某点越陡。）
3. 写出「$f$ 在 $I$ 上**不**一致连续」的严格表述。（提示：逐量词翻转，并把 $\implies$ 拆开。）
4. **（自己造一个）** 把定义里的「$\exists\delta>0$」挪到「$\forall\varepsilon>0$」**之前**（先存在一个 δ，再对一切 ε），概念还一样吗？举一个满足它的函数。

> **迁移练习**：用「假设基底 + 删条件实验」两招，试着自己拆一个**对偶概念**（如「一致收敛」）——先写一句「我猜你已经会……」，再改它的定义看会冒出什么反例。

<details>
<summary>参考答案</summary>

1. **假**。$(0,1)$ 是**开**区间，不是闭区间，闭区间上连续才必然一致连续。反例见第 2 题。
2. $f(x)=\dfrac{1}{x}$ 在 $(0,1)$ 上：连续，但不一致连续。取 $\varepsilon=1$，对任意 $\delta>0$，都能在 0 附近找到相距小于 $\delta$ 的两点，而函数值差超过 1。
3. $\exists \varepsilon>0,\ \forall \delta>0,\ \exists x_1,x_2\in I$，使 $\lvert x_1-x_2\rvert<\delta$ **且** $\lvert f(x_1)-f(x_2)\rvert\ge \varepsilon$。
4. **不一样，强得多**。「先存在 δ、再对一切 ε」即要求 $\lvert f(x_1)-f(x_2)\rvert<\varepsilon$ 对**一切** $\varepsilon>0$ 成立，
   于是 $\lvert f(x_1)-f(x_2)\rvert=0$：只要 $\lvert x_1-x_2\rvert<\delta$ 就有 $f(x_1)=f(x_2)$。
   也就是说，$f$ 在每个长度 δ 的小区间上都是**常数**——在连通区间上只能是**常数函数**。
   满足它的例子：$f(x)\equiv C$（常函数）。可见把 $\exists\delta$ 提到最前，概念几乎塌掉。

</details>
