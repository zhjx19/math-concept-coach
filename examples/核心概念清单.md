# 大学数学核心概念清单

> 这份清单有两个用途：
> 1. **学生自查**：下面每个概念，问自己一句「我能把它讲给别人听吗？」——
>    会做题 ≠ 真理解。答不上来的，就是该拿去拆的概念。
> 2. **教师备课**：挑概念批量生成概念卡，开学第一天就能发给学生。
>
> **认知动作**一列来自本技能 F5 的设计三问（见 `references/visualization-guide.md`），
> 标明该概念适合用哪种交互组件演示；「—」表示纯结构概念，宜用表格与图谱，不宜硬画曲线。
>
> 章节以常见教材为参照（《数学分析》华东师大版体系、《高等代数》北大版第五版），
> **具体节次请与你所用教材核对**。

## 怎么用这份清单

```bash
# 挑一个概念，让技能拆给你看
「怎么理解一致连续？」

# 想批量备课：一次给多个概念
「把上面清单里《高等代数》§3 和 §4 的概念各做一张卡」
```

生成的概念卡是**单文件离线 HTML**：双击即可打开，可拖滑块、可打印、可发给学生，断网也能用。
