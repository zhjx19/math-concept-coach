边界例 4 ⭐ 似然比 =1=1 时，证据毫无信息

由赔率形式：后验赔率=先验赔率×LR\text{后验赔率}=\text{先验赔率}\times\mathrm{LR}。若 LR=1\mathrm{LR}=1，则后验赔率 == 先验赔率，后验 == 先验。 实算：p0=0.001,LR=1p_0=0.001,\ \mathrm{LR}=1，连续 5 次独立观测全为阳性 ⟹ 后验仍是 0.0010.001，一分未动 ✓ 「有病报阳」与「没病报阳」一样可能时，检测连一丝信息都没提供。

F2 通俗理解

一句人话：贝叶斯定理是「把因翻过来当果用」—— 而翻过来之前，必须先把「这个因本来有多常见」放进去。

类比 · 侦探破案 - 似然 P(E∣有罪)P(E\mid\text{有罪})：有罪的人留下这种痕迹的可能性，这是可以靠取证积累的； - 先验 P(有罪)P(\text{有罪})：在所有嫌疑人里，有多少比例本来就有罪 —— 这是推理开始之前就有的背景知识； - 后验 P(有罪∣E)P(\text{有罪}\mid E)：看到这条痕迹之后，嫌疑人的天平偏了多少。

失效边界（三条）

  • 类比只在「背景知识可靠」时成立：先验若取得有偏（只在「已知可疑」的名单里统计），整个后验都被污染 —— 这是「检察官谬误」的来源（见错位清单）。
  • 类比会让人以为「先验可以被证据洗掉」：实际上它只被乘上，不会被替换（边界例 1、4）。
  • 类比里「痕迹」不能是「侦探自己挑的」：取证方式若与结论相关（只查有罪者才有的证据），似然就失真 —— 这在统计上叫选择偏差。

为什么需要它：绝大多数现实问题给的是「结果」（阳性、异常、报警），要问的是「原因」（病、故障、犯罪）。贝叶斯定理是唯一能把结果翻译回原因的概率工具。

F3 严格数学表述

定义

定义（先验 / 似然 / 后验）　设 θ\theta 是取值于空间 Θ\Theta 的未知参数（或原因），xx 是观测到的数据。 - 先验分布：P(θ)=Pθ(Θ∈⋅)P(\theta)=P_\theta(\Theta\in\cdot)，在看到 xx 之前对 θ\theta 的信念； - 似然：P(x∣θ)P(x\mid\theta)，固定 θ\theta 时数据 xx 出现的可能性； - 后验分布：P(θ∣x)P(\theta\mid x)，看到 xx 之后对 θ\theta 的信念。

量词骨架：P(θ∣x)P(\theta\mid x) 的定义要求 P(x)>0P(x)>0；若 P(x)=0P(x)=0 则无定义（同《条件概率与全概率公式》卡边界例 3）。

定理一（贝叶斯定理 · 离散形式） 设 {θ1,…,θk}\{\theta_1,\dots,\theta_k\} 列举全部可能原因，P(θi)>0P(\theta_i)>0。则对任一 ii： P(θi∣x)=P(x∣θi)P(θi)∑j=1kP(x∣θj)P(θj)\boxed{P(\theta_i\mid x)=\frac{P(x\mid\theta_i)\,P(\theta_i)}{\sum_{j=1}^{k}P(x\mid\theta_j)\,P(\theta_j)}} 分母即全概率公式给出的 P(x)P(x) ⟹ 贝叶斯公式 = 全概率公式的「解」。验算：∑iP(θi∣x)=∑iP(x∣θi)P(θi)P(x)=1\sum_iP(\theta_i\mid x)=\frac{\sum_iP(x\mid\theta_i)P(\theta_i)}{P(x)}=1 ✓

推论（未归一化形式）★实用 P(θ1∣x):P(θ2∣x):⋯:P(θk∣x)=P(θ1)P(x∣θ1):⋯:P(θk)P(x∣θk)P(\theta_1\mid x):P(\theta_2\mid x):\cdots:P(\theta_k\mid x)\ =\ P(\theta_1)P(x\mid\theta_1):\cdots:P(\theta_k)P(x\mid\theta_k) 只需比值时不必算分母** —— 这在贝叶斯网络里被用到极致（每个节点只与父节点比）。

**定理二（赔率形式 / 奥德斯比值形式）★本卡最实用的一条 P(θ∣x)1−P(θ∣x)⏟后验赔率=P(θ)1−P(θ)⏟先验赔率×P(x∣θ)P(x∣θ¯)⏟似然比LR\boxed{\ \underbrace{\frac{P(\theta\mid x)}{1-P(\theta\mid x)}}_{\text{后验赔率}}\ =\ \underbrace{\frac{P(\theta)}{1-P(\theta)}}_{\text{先验赔率}}\ \times\ \underbrace{\frac{P(x\mid\theta)}{P(x\mid\overline\theta)}}_{\text{似然比}\ \mathrm{LR}}\ }

依据：把定理一的分子分母都写成「含 θ\theta 的项 + 不含 θ\theta 的项」后相除即得。 实算核对（工厂例）：先验赔率 =0.40.6=23=\frac{0.4}{0.6}=\frac23；LR=0.050.03=53\mathrm{LR}=\frac{0.05}{0.03}=\frac53；乘积 =109=\frac{10}{9} ⟹ 后验 =10/91+10/9=1019≈0.526316=\frac{10/9}{1+10/9}=\frac{10}{19}\approx0.526316 ✓ 与定理一完全一致 （疾病例）：先验赔率 =0.0010.999=0.001001=\frac{0.001}{0.999}=0.001001；LR=99\mathrm{LR}=99；乘积 =0.0990991=0.0990991 ⟹ 后验 =0.0901639=0.0901639 ✓

为什么这一条最好用：在赔率尺度上，「更新」就是一次乘法。 而且 LR\mathrm{LR} 是一个与先验无关的量 —— 它纯粹由「检验有多灵」决定，可以事先单独标定、复用。

定理三（连续情形 · 密度形式） 设 θ\theta 有密度 f(θ)f(\theta)，x∣θx\mid\theta 的条件密度为 f(x∣θ)f(x\mid\theta)，则 f(θ∣x)=f(x∣θ)f(θ)f(x),f(x)=∫Θf(x∣θ)f(θ)dθf(\theta\mid x)=\frac{f(x\mid\theta)f(\theta)}{f(x)},\qquad f(x)=\int_{\Theta}f(x\mid\theta)f(\theta)\,\mathrm d\theta > ⚠ 关键差别：离散情形分母是求和，连续情形是积分；且 f(x)f(x) 是一个数（在 xx 处的边缘密度），不是一个概率。「求和」直接换成「积分」是本卡最容易出错的一步。

定理四（序贯更新 / 贝叶斯更新）★第二条实用主线 若 x1,…,xnx_1,\dots,x_n 在给定 θ\theta 时条件独立，则 f(θ∣x1,…,xn)∝[∏i=1nf(xi∣θ)]f(θ)f(\theta\mid x_1,\dots,x_n)\ \propto\ \Big[\prod_{i=1}^{n}f(x_i\mid\theta)\Big]\,f(\theta) 精确的说法：「似然连乘，先验不变。」 先验只乘一次，似然乘 nn 次。 等价地（赔率）：后验赔率=先验赔率×∏iLRi\text{后验赔率}=\text{先验赔率}\times\prod_i\mathrm{LR}_i 实算核对（p0=0.001,LR=99p_0=0.001,\ \mathrm{LR}=99，连续 nn 次全阳性）： n=1⇒0.090164n=1\Rightarrow0.090164；n=2⇒0.907500n=2\Rightarrow0.907500；n=3⇒0.998971n=3\Rightarrow0.998971 （闭式 oLRn1+oLRn\frac{o\,\mathrm{LR}^n}{1+o\,\mathrm{LR}^n} 与逐次迭代 θ←LRθ1−θ+LRθ\theta\leftarrow\frac{\mathrm{LR}\theta}{1-\theta+\mathrm{LR}\theta} 逐项相同 ✓） ⟹ 后验会「饱和」：n=3n=3 时已到 99.9%99.9\%，再多数据也不会更接近 11，只会更接近真实值（这里是 11，因为 LR=99\mathrm{LR}=99 恒定）。

F4 几何 / 物理意义
  • 「先验 × 似然 = 未归一化后验」是一块「面积」：{θ}\{\theta\} 是横轴，未归一化后验 P(x∣θ)P(θ)P(x\mid\theta)P(\theta) 是一条曲线，贝叶斯定理就是用分母把这块面积归一化成 11。归一化后的曲线就是后验密度。
  • 赔率形式 = 在对数尺度上的平移：log⁡P(θ∣x)1−P(θ∣x)=log⁡P(θ)1−P(θ)+log⁡LR\log\frac{P(\theta\mid x)}{1-P(\theta\mid x)}=\log\frac{P(\theta)}{1-P(\theta)}+\log\mathrm{LR} ⟹ 一次更新 = 一次加法。这就是为什么 log\log（对数几率）在统计与机器学习里无处不在（logistic 回归的名字就来自这里）。
  • 回指 F3：定理五的后验方差 =11/σ2+1/τ2=\frac{1}{1/\sigma^2+1/\tau^2} 是精度并联——像电路里两条支路的电导相加。物理直觉：先验与数据是两个「独立的信息源」，精度（方差倒数）直接相加。
  • 物理类比 · 弹簧测力与重力：xx 是「弹簧被拉长多少」，σ2\sigma^2 是「秤的噪声」，μ0,τ2\mu_0,\tau^2 是「你手里那块砝码的标称重量与公差」。贝叶斯更新 = 把砝码和秤合在一起读数（两者的精度并联）。砝码越重（τ2\tau^2 小）读数越接近标称值，秤越精确（σ2\sigma^2 小）读数越接近被测物 —— 公式里权重是「精度倒数」正好符合直觉。

def bayes_odds(p0, lr, n=1):
    o = p0 / (1 - p0)            # 先验赔率
    po = o * lr ** n             # 后验赔率 = 先验赔率 × 似然比^n（似然连乘，先验不变）
    return f"prior_odds={o:.6g} lr={lr:.6g} n={n} post_odds={po:.6g} post={po/(1+po):.6g}"
def alpha_vs_actual(alpha, power, prior_h0):

            f" -> actual P(H0|D)={alpha*prior_h0/(alpha*prior_h0+power*(1-prior_h0)):.6g}")

说到「贝叶斯定理」，你要想到……（闭卷 60 秒，≥4 条才算过）

  1. P(θ∣x)=P(x∣θ)P(θ)P(x)P(\theta\mid x)=\frac{P(x\mid\theta)P(\theta)}{P(x)}；分母是全概率给的，分子是「似然 × 先验」。
  2. 未归一化形式：只比 P(θ)P(x∣θ)P(\theta)P(x\mid\theta) 的大小即可 ⟹ 贝叶斯网络的基础。
  3. 赔率形式：先验赔率 × 似然比 == 后验赔率；LR\mathrm{LR} 与先验无关，可单独标定。
  4. 序贯更新：似然连乘、先验只乘一次；后验会饱和。
  5. 连续情形分母是积分，不是求和；分母是密度值不是概率。
  6. 共轭先验（正态–正态）：后验均值 == 先验均值与观测值按精度倒数加权平均；后验方差 =11/σ2+1/τ2=\frac{1}{1/\sigma^2+1/\tau^2}。
  7. 朴素贝叶斯的「朴素」＝ 给定类别时特征互相独立；必须取对数防下溢。
  8. 名义错误率 α=P(⋅∣H0)\alpha=P(\cdot\mid H_0) ≠ 实际错误概率 P(H0∣⋅)P(H_0\mid\cdot)；后者依赖先验。
  9. LR=1\mathrm{LR}=1 ⟹ 证据零信息，看多少次后验都不动。
  10. 「先验 × 似然」的乘积曲线除以总面积 = 后验曲线（贝叶斯 = 归一化）。

常见错位清单（〔〕内是错误来源）

  1. 〔字眼漏读〕把 P(阳性∣病)P(\text{阳性}\mid\text{病})（似然）当成 P(病∣阳性)P(\text{病}\mid\text{阳性})（后验）—— 99%→9%99\%\to9\%。
  2. 〔定理当定义〕把「名义错误率 α\alpha」当成「这个结果错的概率」—— 前者是 P(⋅∣H0)P(\cdot\mid H_0)，后者是 P(H0∣⋅)P(H_0\mid\cdot)。
  3. 〔量词顺序 / 忽略先验〕以为「有数据就不用先验」—— 先验是乘积里的因子，不是可省略项。
  4. 〔类比越界〕以为「证据越多越接近真相」—— 似然比固定时后验会饱和；LR=1\mathrm{LR}=1 则永不移动。
  5. 〔字眼漏读（法证）〕把「无罪释放率」P(无罪∣被告)P(\text{无罪}\mid\text{被告}) 当成 P(被告∣无罪)P(\text{被告}\mid\text{无罪}) —— 这就是缺失因子问题。
  6. 〔定理当定义〕以为「先验 P(θ)P(\theta) 必须是客观频率」—— 主观贝叶斯派主张它可以是信念；分歧在哲学不在算术。

⚠️ 核对提示（请以你所用教材为准）

  1. 定理一的名称与写法 〔教材口径〕 本卡把 P(θi∣x)=P(x∣θi)P(θi)∑jP(x∣θj)P(θj)P(\theta_i\mid x)=\frac{P(x\mid\theta_i)P(\theta_i)}{\sum_jP(x\mid\theta_j)P(\theta_j)} 称贝叶斯定理 / 贝叶斯公式，并把 P(x)=∑jP(x∣θj)P(θj)P(x)=\sum_jP(x\mid\theta_j)P(\theta_j) 单独称为全概率公式（那是上一张卡的内容）。有的教材把二者合称「全概率公式与贝叶斯公式」，或把分母那部分叫「全概」。名称不同，公式一致。

  2. 先验的哲学地位 〔教材口径〕 F6 的「平移」栏提到频率派与贝叶斯派的对立。「先验是不是客观概率」在教材里往往只做一句话交代；本卡 F2 与「自检题」都提到了主观先验的可能。具体立场请以你教材的论述为准，本卡不选边。

  3. 定理五共轭先验的记号约定 〔教材口径〕 本卡用「σ2=\sigma^2= 观测噪声方差、τ2=\tau^2= 先验方差」。不同教材可能把两者记号互换（如用 τ2\tau^2 表示观测噪声）。代入公式前先确认哪个是数据、哪个是先验。

  4. 「可信度区间 / 区间概率」的严格表述 〔教材口径〕 定理七、七、八给出的是离散两情形（H0H_0 与 H0¯\overline{H_0}）下的换算。连续参数下「P(θ∣x)≥αP(\theta\mid x)\ge\alpha」对应的区间称为后验可信区间（或贝叶斯可信区间、HPD 区间、可信带），其定义细节（是否取最短长度、是否等尾）与「置信区间」的差异各家教材处理不同。本卡未展开，请按你教材。

  5. 朴素贝叶斯的连续特征 〔教材口径〕 定理六写成 P(xj∣ck)P(x_j\mid c_k)。若 xjx_j 是连续变量，正确写法是密度 f(xj∣ck)f(x_j\mid c_k)，其量纲不是概率。连续特征下这套公式仍成立，但必须用密度，且概率测度需换成 Lebesgue 测度。 本卡未强调这一条，请你在做题时留意。

  6. MCMC 采样 〔教材口径〕 F6 的「上楼」栏点到「非共轭时用 MCMC 从 f(θ∣x)f(\theta\mid x) 采样」。这属于贝叶斯计算 / 统计计算的高阶内容，多数初等概率教材不涉及。本卡仅作方向指引，不给任何公式。
