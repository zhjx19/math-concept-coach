# 六棱镜拆解手册（SIX-FACET）

> 一个概念 = 一颗宝石。单看一面，学生只记住一个影子；转六面，学生才拿到**立体**的理解。
> 本手册规定每一面「做什么、怎么做、做到什么程度算好、常见错误是什么」。**每一面都要落地，不得跳过。**

## 总览

| 编号 | 棱镜面 | 一句话目标 | 主要打在学生的哪个通道 |
|---|---|---|---|
| **F1** | 正反拆解 | 划定概念的**边界**：是它 / 不是它 | 反例驱动 |
| **F2** | 通俗理解 | 说一句**人话**，并说明为什么需要它 | 直观/背景 |
| **F3** | 严格数学表述 | 用**量词与符号**精确写出，逐字抠 | 严格符号 |
| **F4** | 几何 / 物理意义 | 它在**空间或现实**里长什么样 | 直观/背景 |
| **F5** | 图形化演示 | 让学生**看见**它随参数变化 | 直观 → 严格 的桥 |
| **F6** | 联系其它概念 | 把它挂进**知识大厦**的哪一层 | 依赖关系 |

**内在逻辑**：F1 先划界（举例子、找边界，逼出「为什么定义要这么写」）→ F2 说人话 → F3 给出严格版并做删条件实验 → F4/F5 把严格版「翻译」回感知 → F6 放回体系。**F1 与 F3 是骨架，F2/F4/F5 是让骨架长出血肉，F6 是让它站起来。**

> **为什么是这六面（回应「是否 MECE」）**：六棱镜是按**表征通道**划分的——反例 → 口语 → 符号 → 空间 → 图形（可操作）→ 依赖。
> F2/F4/F5 都服务「直观」，但**载体不同**（说人话 / 空间想象 / 动手实验），并不重复；而**过程维度**（如何用它证明/构造）由 F3 的「操作骨架」补上。
> 记忆锚点：**看见边界（F1）→ 说得出（F2）→ 写得准（F3）→ 想见形（F4）→ 动得手（F5）→ 挂得上（F6）。**

> **六面之外还有一本「过程手册」**（`process-playbook.md`）：本手册管「**讲清楚**」，过程手册管「**用得上**」——通用求解程序、理解度判据、反例构造手法、误区来源诊断。拆解时两者配合使用。

## F0 钩子与假设基底（六棱镜之前，必须先做）

> 借用同行 math-concept-film 的「钩子 / 地图」两幕：
> **先想清楚"学生看完能复述哪一句"，再想"他现在站在哪、缺哪块"。**

### 一句话钩子

写完整个拆解后，必须能提炼出**一句学生能向别人复述的大白话**——
不是定义，不是性质，而是"它到底在说什么"。

| 概念 | ❌ 不算钩子 | ✅ 算钩子 |
|---|---|---|
| 一致连续 | 「$\forall\varepsilon>0\ \exists\delta>0\dots$」 | 「同一个 δ 要能管住整条区间，不能每换一个点就换一把尺子」 |
| 数列极限 | 「无限接近」 | 「不管你尺子划多细，数列从某一项往后都待在里面」 |
| 矩阵的秩 | 「非零子式的最高阶」 | 「这个变换把空间压扁到了几维」 |

**检验标准**：把这句话念给一个没学过该概念的同学，他能复述出来，并且**不会因此产生新的误解**。做不到就重写。

### 假设基底（是「待验证的假设」，不是判决书）

动笔前写三个问题，但**措辞必须是"邀请确认"，不是"单方宣判"**（写进卡片开头）：

1. **我猜你已会**：把前置概念列成**猜测**，而非断言（列 2–4 个，不要想当然）。
2. **我觉得你可能缺**：从"已会"到"本概念"之间，**可能断掉的那一步**是什么。
3. **本概念补哪块**：本概念正是用来补上这个断点。

**必须跟着一句追问**：「**你觉得自己会吗？**」——若学生说不会 / 不确定，**先出 1 道诊断题**（见 SKILL 第 1 步），让他自己暴露断点，再据此**修正**基底。

> **诊断题要照「误区来源」下钩，不要随机抽查。** 学生的错通常有六种来源——**中学残留 / 教材省略 / 字眼漏读 / 量词顺序 / 定理当定义 / 类比越界**。
> 先判学生可能落在哪一类，再出打这一类的题（六类来源的典型表现与对症处置见 `process-playbook.md` 第四节）。
> 例：怀疑是「中学残留」，就问边界例；怀疑是「字眼漏读」，就问「这个词删了会怎样」。

> 为什么要这样写：大一新生的困难通常不是"不懂某一步"，而是**整个直觉框架还是中学的**。
> 但**"你缺哪块"若由 AI 单方点名，学生未必认同**（概念转变需要学习者认可新框架的合理性）。
> 把断言改成**邀请 + 诊断**，学生才会真正接住这块基底。把"我以为你会、其实你还不会"的那一步**点名**，比把定义多讲三遍有效。

**与 F6 的分工**：F0 的假设基底是**入口**（进来前站在哪），F6 的知识图谱是**出口**（出去后通向哪）。两者不重复，缺一不可。

## F1 正反拆解：概念不是「像什么」，而是「边界在哪」

### 操作三步（固定动作）

1. **给正例**：2–3 个典型例子（越典型越好，让学生先建立「这就是它」）。
2. **给边界例**：刚好踩在线上、差一点就不是的例子（最能暴露理解的裂缝）。
3. **给反例**：明确「不是它」的例子，并**指出它违反了哪一条**。

> **删条件实验不在本面**——它依赖「定义里的条件」，故归到 **F3**（先给定义，再逐字删）。
> F1 的职责是把边界摆出来：**让学生先凭直觉看到「是它 / 不是它」，带着疑问进入 F3。**

### 话术模板

- 「下面三个，哪些符合这个定义？先别看定义，凭直觉判断。」
- 「这个例子差在哪里？它满足了定义的前几条，卡在第几条？」
- 「这个词听起来像，但它和那个概念差在哪？」

### 常见错误（教练自查）

- ❌ 只给正例，不给反例 → 学生把概念学成「一种感觉」。
- ❌ 反例本身有错（**最严重**）→ 宁可留空让学生自己构造，也不写没把握的反例。
- ❌ 把「难算的例子」当反例（反例不等于计算复杂）。
- ❌ 边界例没点出「差一点」差在哪 → 学生看不出裂缝在哪。

> **想不出反例怎么办**：反例不是灵光一闪，是**按手法造出来的**——推边界 / 造振荡 / 换定义域 / 取退化值 / 造子列 / 造「坏点对」，六法及经典例子见 `process-playbook.md` 第三节。
> 造完**必须代进定义验算一遍**再写；算不出来的，改成「请你试着构造一个反例」（纪律红线 3、8）。

## F2 通俗理解：一句人话 + 一个类比 + 一条边界

### 操作三步

1. **一句人话**：把概念翻译成**不带术语**的一句话（先给「它在干什么」，不是「它是什么」）。
2. **一个类比**：生活/几何类比，**必须**补一句「在哪失效」。
3. **为什么要它**：这个概念**解决了什么问题**／是**对什么现象的抽象**。学生不关心「为什么需要它」，就永远记不住。

### 好 / 坏示范

| 概念 | ❌ 坏（伪通俗） | ✅ 好（有边界的人话） |
|---|---|---|
| 数列极限 | 「就是无限接近」 | 「不管你划多细的尺子（ε），数列从某一项往后都待在目标附近这么细的范围内」；**边界**：『接近』不是『相等』，且必须『任意小的 ε 都能做到』——只能做到某一个 ε 不算。 |
| 线性相关 | 「就是有关系」 | 「这组向量里有『多余的』——去掉它不损失信息」；**边界**：说『多余』要指明是相对全体而言，两个向量谈不上谁多余，是『互为倍数』。 |
| 一致连续 | 「就是连续得更均匀」 | 「整段曲线能共用一个『粗细标准』：无论你在哪一段，我都用同一个 δ 保证变化小于 ε」；**边界**：不是『更连续』，连续不分等级——区别只在 δ 是否依赖位置。 |

### 常见错误

- ❌ 类比的边界不标 → 类比变成新误解（「极限就是无限接近」直接导致学生认为 $0.999\ldots < 1$）。
- ❌ 用更难的术语解释难术语（循环解释）。
- ❌ 只顾生动，丢了准确性 → **准确性永远优先于生动**。

### 与 F3 的接缝：「先写人话，再写符号」

F2 讲完不是就完了——**F2 与 F3 之间必须有一道看得见的桥**，否则学生听到的仍是两段互不相关的话。

标准动作：**每一步先给日常说法，紧接一句「用严格数学语言来说，就是……」**。

> 例（数列极限）：
> 「不管你给的接近程度 $\varepsilon$ 有多小，$a_n$ 到 $A$ 的距离都能比它更小」
> → **用严格数学语言来说**：$\forall\varepsilon>0,\ \exists N,\ \forall n>N:\ \lvert a_n-A\rvert<\varepsilon$。

**为什么要这道桥**：学生真正的卡点常常既不在「不懂人话」，也不在「不懂符号」，而在**不知道这两句话说的是同一件事**。把桥明写出来，符号才有落点。

## F3 严格数学表述：逐字抠，一个词都不放过

> 详见 `rigorous-language.md`。本面只规定**动作**。

### 操作七步

1. **原样写出**：完整抄写定义/定理（标明教材出处，避免自造表述）。
2. **标出量词结构**：用 `∀ / ∃` 把逻辑骨架抽出来。
3. **删条件实验** ⭐（本面最重要的动作）：逐个删掉定义里的条件，问「现在会出现什么反例？」
   - **为什么关键**：定义里的每个词都在「防守」一个反例；学生只有看到「删掉这个条件 → 反例立刻冒出来」，才会相信定义**不能改一个字**。
   - 话术：「这条限制能删吗？删了以后你能不能举出一个反例把它证伪？」
   - 话术：「把『存在 M』改成『对每个 M 都存在 x 使 |f(x)| > M』，它还是原来那个概念吗？」
   - ⚠️ 只做形式、不给具体反例 = 白做；每个删法都要**落到一个反例上**。
4. **区分身份**：这是**定义**（人为约定，不问对错、只问合理性）还是**定理**（需要证明）？**学生最常把定义当定理去「证」，或把定理当定义去「用」。**
5. **给出等价表述**（若有）：并说明等价是需要证明的，不是当然的。
6. **给出操作骨架**（过程维度）：写清「**如何用它做一次证明 / 构造**」的步骤模板。例如 ε–N 证明的固定写法：
   ① 任给 ε>0 → ② 解不等式 |aₙ−a|<ε，反求出 N(ε) → ③ 取 N=⌈…⌉ → ④ 验证 n>N 时成立。
   > **学生会「看定义」不等于会「用定义」**——这一步补的就是"从 Object 到 Process"的缺口（APOS）。
7. **带读一条证明**：挑一条相关定理，**逐行读它的证明**，每行问一句「这一步的依据是什么」。
   > **定理不能只背结论**——只会背结论等于没学会定理。读证明既加深对本概念的理解，也顺带练逻辑推理（这正是大学数学最该练的能力）。

> **「怎么用它做题」的通用程序**：本面的「操作骨架」是**某一类定义**的固定写法；而拿到**任意一道题**怎么开局，见 `process-playbook.md` 第一节的**「两头往中间」**——① 拆题设 ② 拆结论 ③ 两头夹 ④ 顺写。**骨架是肌肉记忆，程序是行动路线，先有开局再用骨架。**

### 三种身份辨别表（务必讲清）

| 身份 | 特点 | 学生易错 |
|---|---|---|
| **定义** | 人为规定，不证；只讨论「是否合理 / 是否有用」 | 试图证明定义 |
| **定理** | 必须由定义+已有定理证明 | 直接使用而不看前提条件 |
| **约定/记号** | 为书写方便 | 把记号当结论 |

### 常见错误

- ❌ 用自然语言混过量词（「对很小的 ε，存在 δ」——缺了「任意」）。
- ❌ 量词顺序写反（`∀ε∃δ` 与 `∃δ∀ε` 是两个世界，见 `rigorous-language.md`）。
- ❌ 不标出处，凭记忆默写定义 → 出错且学生无法核对。

## F4 几何 / 物理意义：让它「看得见、摸得着」

### 操作

1. **几何图像**：概念在坐标系/空间中对应什么图形、什么位置关系、什么「动」？
2. **物理场景**（有则给）：速度-加速度、位移-时间……用学生熟悉的现象锚定。
3. **若没有直观**：**诚实说明**「这个概念的直观在更高维/更抽象处，现阶段先用符号定义为准」——**不要硬编一个假直观**。
4. **回指严格定义**：讲完意义，**必须**回到 F3 的式子，指出「这个图像对应式子里的哪一项」。

> **纪律**：几何/物理意义是**辅助理解**，不是**证明依据**。图形能帮你「想到」，但结论要靠 F3 的推理。这一点要明确告诉学生。

### 概念 → 图像 套路速查

| 概念 | 几何/物理图像 |
|---|---|
| ε–N 极限 | 数轴上「禁区」外的项只剩有限个 |
| ε–δ 连续 | 横 ε 带 ↔ 纵 δ 带 的「盒子」 |
| 一致连续 | 全区间共用**同一个宽度的 δ 盒子** |
| 导数 | 割线 → 切线的极限位置 |
| 定积分 | 曲边梯形面积、黎曼和的极限 |
| 线性相关 | 向量共线（2个）/ 共面（3个） |
| 矩阵的秩 | 像空间的维数 / 有效信息量 |
| 特征值 | 方向上不被扭转、只被拉伸的倍数 |

## F5 图形化演示：让学生「拖一下，看变化」

> 详见 `visualization-guide.md`。本面只规定**教学动作**。

### 关键：图形不是配图，是**实验台**

- 必须给学生一句**操作指令**：「拖动 δ，观察 ε 带里的曲线是否始终不掉出去」。
- 必须让学生**先预测后验证**：「你觉得 δ 调小到多少，曲线会跑出去？」→ 再拖。
- 动态优先于静态：能拖参数的概念，**不要**只给静态图。

### 常见错误

- ❌ 给一张「漂亮但静态」的图，学生看完还是不懂 → 没有操作指令的图 = 装饰。
- ❌ 图画得和严格定义对不上 → 图必须能回指 F3。
- ❌ 过度花哨，喧宾夺主。

## F6 联系其它概念：把它挂进「知识大厦」

### 先让学生自己建（不要一上来就给图）

**动手在前**：先问学生——「在学这个概念**之前**，你觉得**必须先会哪 3 个东西**？写下来。」
让他先凭记忆列，**再**对照下面这张知识图谱，看漏了哪个、多列了哪个。

> 图式被「给予」不如被「建构」：自己列过一遍，图谱才挂得住（Chi：接收 ≠ 建构）。

### 操作三问（必须都答）

1. **下楼（它靠什么）**：这个概念建立在哪些更基本的概念之上？前置是什么？
2. **上楼（它支撑什么）**：由它能推出哪些定理 / 被哪些结论使用？
3. **平移（同类与对偶）**：它和哪些概念是「同类」或「对偶」？（如 连续↔一致连续、收敛↔一致收敛、线性相关↔线性无关、满射↔单射）

### 输出形式

- **先收学生列的清单**（圈出对、漏、多），再给一张**小关系图**（文字版亦可，如 `前置 → 本概念 → 后续定理`）。
- 明确指出**它是这座大厦的哪一层**（基础定义 / 中间定理 / 高层结论）。

### 常见错误

- ❌ 只列「相关概念」名单，不说**关系方向**（谁推出谁）。
- ❌ 挂错楼层（如把「一致连续」说成比「连续」更基础的，恰好相反）。

# 完整范例：用六棱镜拆解「一致连续」（数学分析）

> 这是**样板**。教练应达到这个密度和深度。

### F1 正反拆解
- **正例**：$f(x)=x$、$f(x)=\sin x$ 在 $\mathbb{R}$ 上一致连续；$f(x)=\sqrt{x}$ 在 $[1,+\infty)$ 上一致连续。
- **边界例**：$f(x)=x^2$ 在 $[0,1]$ 上**一致连续**（闭区间连续必一致连续），但在 $\mathbb{R}$ 上**不是**——同一个函数，换个定义域，结论反了。**这一例最能逼学生明白「一致连续是定义域与函数一起谈的性质」。**
- **反例**：$f(x)=\dfrac{1}{x}$ 在 $(0,1)$ 上连续但**不一致连续**。它违反了「δ 只依赖 ε、不依赖位置」这一条：越靠近 0，要达到同一个 ε 需要的 δ 越小。

### F2 通俗理解
- **一句人话**：「整段曲线能**共用一套宽容标准**：无论你站在哪一段，我都能用同一个 δ，保证函数值的变化小于你给的 ε。」
- **类比**：像一把**统一刻度的尺子**量整条曲线——连续的函数每一点都能量，但尺子可以一点一换；一致连续要求**换点不换尺**。
- **为什么要它**：为了让「闭区间上连续函数可积」「极限运算可交换」这类定理有落脚点；它把「逐点的性质」升级成「整体的性质」。
- **类比边界**：别说「一致连续就是更连续」——连续不分强弱；差别**只在 δ 是否依赖位置**。

### F3 严格数学表述
定义（设 $f$ 在区间 $I$ 上有定义）：
$$f \text{ 在 } I \text{ 上一致连续} \iff \forall \varepsilon>0,\ \exists \delta>0,\ \forall x_1,x_2 \in I,\ \lvert x_1-x_2\rvert<\delta \implies \lvert f(x_1)-f(x_2)\rvert<\varepsilon.$$
对比**连续**（逐点）：
$$\forall x_0\in I,\ \forall \varepsilon>0,\ \exists \delta>0,\ \forall x\in I,\ \lvert x-x_0\rvert<\delta \implies \lvert f(x)-f(x_0)\rvert<\varepsilon.$$
- **量词结构**：一致连续是 $\forall\varepsilon\,\exists\delta\,\forall x_1\,\forall x_2$（δ 在 $x_1,x_2$ **之前**）；连续是 $\forall x_0\,\forall\varepsilon\,\exists\delta\,\forall x$（δ 在 $x_0$ **之后**，可依赖 $x_0$）。**δ 位置的先后，就是本质区别。**
- **删条件实验**：把「$\forall x_1,x_2\in I,\ \lvert x_1-x_2\rvert<\delta$」改成「固定 $x_0$，$\lvert x-x_0\rvert<\delta$」——概念立刻退化为**连续**。这就是两者的全部差别。
- **身份**：这是**定义**（人为规定的性质），不要试图去「证明」它。
- **操作骨架**（怎么证一致连续）：① 任给 ε>0 → ② 找一个**不依赖位置**的 δ(ε)（常用 Lipschitz 估计 $|f(x_1)-f(x_2)|\le L|x_1-x_2|$，或中值定理）→ ③ 取 δ 使 $L\delta\le\varepsilon$ → ④ 验证。
- **等价表述**：在不一致连续时，$\exists\varepsilon>0$ 使对每个 $\delta>0$ 都有「坏点对」——这是否定式，证明「不一致连续」时用。

### F4 几何意义
- 图像上：把曲线放进一个「**横向 ε 带、纵向 δ 带**」的可滑动矩形框里。连续只要求**在每个位置**都能塞进某个 δ 框；一致连续要求**全区间用同一个宽度的 δ 框**。
- 曲线越陡的地方越要更小的 δ；一致连续 = 陡峭程度整体上「被控制住」，无一处可以任意陡。$1/x$ 在 0 附近越来越陡，于是失守。
- **回到式子**：这个「同一个 δ」正是 F3 里 $\exists\delta$ 出现在 $\forall x_1,x_2$ **之前**的几何含义。

### F5 图形化演示
- **GeoGebra**：画 $f(x)=\sin(1/x)$ 于 $(0,1)$ 或 $f(x)=x^2$；做滑动条 $\delta$、$\varepsilon$，显示「坏点对」出现的位置。
- **操作指令**：「拖动 δ 从大到小，观察在哪个位置曲线开始冲出 ε 带？把这个 δ 记下来，再换一个位置试试，能不能用同一个 δ？」
- **预测**：先问「$1/x$ 在 (0,1) 上，越靠近 0 需要 δ 越大还是越小？」→ 再拖验证。

### F6 联系其它概念
- **下楼（前置）**：函数、极限、连续、区间的概念。
- **上楼（支撑）**：闭区间上连续 ⟹ 一致连续（Cantor 定理）；一致连续 ⟹ 连续；一致连续函数把 Cauchy 列映为 Cauchy 列。
- **平移（同类/对偶）**：与「连续」对偶（局部 vs 整体）；后续还将遇到「一致收敛」（把逐点收敛升级为整体）——**同一个思想母题**。
- **大厦位置**：中间层定理的基础概念，是「从局部走向整体」的第一个范例。

# 简例：用六棱镜拆解「线性相关」（高等代数）

- **F1**：正例——$\{\alpha, 2\alpha\}$ 相关；$\{(1,0),(0,1)\}$ 无关。反例/边界——**含零向量的向量组必线性相关**（取零向量系数为 1、其余为 0）；单个**非零**向量无关，单个**零**向量相关。
- **F2**：「这组向量里有**多余的**——去掉某一个，张成的空间不损失。」边界：s=1 时谈不上「去掉一个还剩同空间」，所以定义要回到「存在不全为零的系数」这个统一形式。
- **F3**：$\alpha_1,\dots,\alpha_s$ 线性相关 $\iff \exists k_1,\dots,k_s$ **不全为零**，使 $\sum k_i\alpha_i=0$。线性无关 $\iff$ 由 $\sum k_i\alpha_i=0$ **只能推出** $k_1=\dots=k_s=0$。身份：**定义**。等价（$s\ge2$）：相关 $\iff$ 至少有一个向量可由其余线性表出。删条件——把「不全为零」改成「全为零」，则任何向量组都满足，概念塌掉。
- **F4**：2 个向量相关 = 共线；3 个相关 = 共面；一般地 = 「张成的空间维数 < 向量个数」。
- **F5**：GeoGebra/HTML——平面上放 2 个可拖动的向量，实时显示它们是否始终落在同一条直线上；相关时提示「共线」。
- **F6**：下楼——向量、线性组合、方程组；上楼——基、维数、秩、解的结构；平移——与「线性无关」对偶，与「方程组的自由变量」是同一件事的两种说法。
