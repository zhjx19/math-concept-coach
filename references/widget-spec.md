# 图形化组件规范（Widget Spec）

> 概念卡支持四种「特殊代码块」，`scripts/md2card.py` 会把它们渲染成**真实内容**（不是原样显示代码）：
>
> | 代码块语言 | 渲染成 | 用途 |
> |---|---|---|
> | ` ```interactive ` | **可拖动交互图形**（Canvas + 滑块，单文件离线） | F5 图形化演示 |
> | ` ```concept-map ` | **知识图谱**（内联 SVG） | F6 联系其它概念 |
> | ` ```geogebra ` | **GeoGebra 复现指令** + 一键复制按钮 | F5 让学生自己动手 |
> | ` ```sim ` | **Python / R 模拟代码选项卡**（默认 Python，一键复制，可切换 R） | 随机 / 迭代规律的数值演示，散布在需要的面 |
>
> 四种块都必须**顶格写**（可带少量缩进），块内不要出现空行。

## 一、组件选型：什么概念用哪个组件

| 概念类型 | 用哪个 | 典型概念 |
|---|---|---|
| 函数图像随参数变化、ε–δ、曲线上取点连线 | **`plot`** | 极限、连续、一致连续、导数（割线→切线）、中值定理、单调性、凹凸 |
| 离散数列 + ε–N | **`seq`** | 数列极限、收敛、子列 |
| 曲线下面积 / 分割求和 | **`riemann`** | 定积分、黎曼和、达布和 |
| 2 维线性变换、行列式、秩的几何 | **`matrix2`** | 线性变换、行列式、矩阵的秩、可逆、特征方向 |
| 向量的线性组合与张成 | **`vectors2`** | 线性相关/无关、基、张成空间、维数 |

> 都不合适时（如「数域」「欧氏空间」这类纯结构概念）→ **不画**，改为表格 + 结构说明。**不要硬凑图。**

### 表达式语法（`plot` / `seq` / `riemann` / 叠加层通用）

- 幂用 `^`：`x^2`、`x^(1/3)`
- **乘法必须显式写 `*`**：写 `2*x`，**不能**写 `2x`
- 可用函数：`sin cos tan asin acos atan sinh cosh tanh exp log`（=ln）`sqrt abs floor ceil sign min max pow`
- 可用常量：`pi`、`e`
- 自变量：`plot` 用 `x`；`seq` 用 `n`
- **叠加层 / 标记点里可以调用主函数**：写 `f(x0)`、`f(x0+d)`
- 未声明的标识符会被当作变量（取不到值就画不出来）——**变量名必须来自 `sliders`**

## 二、`plot`：函数图像 + 参数滑块

```interactive
{
  "type": "plot",
  "expr": "sin(1/x)",
  "xrange": [0.02, 1],
  "yrange": [-1.35, 1.35],
  "ratio": 0.5,
  "sliders": [
    {"name": "x0", "label": "x₀ 位置", "min": 0.03, "max": 0.9, "step": 0.01, "value": 0.6},
    {"name": "d",  "label": "δ",      "min": 0.005, "max": 0.25, "step": 0.005, "value": 0.06},
    {"name": "eps","label": "ε",      "min": 0.1,  "max": 1.3, "step": 0.05, "value": 0.6}
  ],
  "overlays": [
    {"kind": "hbar",  "y": "f(x0)", "half": "eps", "color": "#f0a53a", "label": "ε 带"},
    {"kind": "vband", "x": "x0",    "half": "d",   "color": "#6aa3d5"}
  ],
  "points": [
    {"x": "x0",   "y": "f(x0)",   "label": "A", "color": "#c2582a"},
    {"x": "x0+d", "y": "f(x0+d)", "label": "B", "color": "#1f8a63"}
  ],
  "segments": [
    {"x1": "x0", "y1": "f(x0)", "x2": "x0+d", "y2": "f(x0+d)", "color": "#c2582a", "dash": [4, 3]}
  ],
  "readout": [
    {"label": "|f(A)−f(B)|", "expr": "abs(f(x0+d)-f(x0))", "digits": 3},
    {"label": "ε", "expr": "eps", "digits": 2}
  ],
  "hint": "把 δ 固定在 0.06，慢慢移动 x₀ 到靠近 0：|f(A)−f(B)| 会冲破 ε。"
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `expr` | ✅ | 主函数表达式 |
| `xrange` / `yrange` | ✅ | 视野范围 `[min, max]`；**务必保证曲线主体在视野内** |
| `ratio` | | 画布高宽比，默认 `0.52` |
| `sliders` | | `{name,label,min,max,step,value}`；**最多 3 个**，多了学生调不过来（`matrix2` / `vectors2` 因结构需要可到 4 个，见 §五、§六） |
| `overlays` | | `hbar`＝水平 ε 带（`y` 中心、`half` 半宽）；`vband`＝垂直 δ 条（`x` 中心、`half` 半宽） |
| `points` | | 曲线上的标记点 |
| `segments` | | 两点连线（割线/切线弦），`dash` 可选 |
| `readout` | | 实时数值显示；`digits` 控制小数位 |
| `hint` | ✅ | **操作引导语**：拖什么、看什么、先预测什么 |

### 现成配方

| 概念 | expr / 滑块 | 叠加层 |
|---|---|---|
| 数列→函数极限（ε–δ） | `expr` 任意；滑块 `x0`、`d`、`eps` | hbar + vband + 点 A、B |
| 导数（割线→切线） | 滑块 `a`、`h`；点 A=`(a,f(a))`、B=`(a+h,f(a+h))`；segment A–B | 另加一条切线用 `segments` 近似 |
| 中值定理 | 滑块 `a`、`b`；`segments` 连 A、B | — |
| 单调性 / 凹凸 | 滑块 `a`；点 `(a, f(a))` | hbar 显示函数值比较 |

## 三、`seq`：数列 ε–N

```interactive
{
  "type": "seq",
  "expr": "1/n",
  "nrange": [1, 60],
  "target": 0,
  "sliders": [{"name": "eps", "label": "ε", "min": 0.01, "max": 0.5, "step": 0.01, "value": 0.1}],
  "hint": "拖动 ε，看 N 怎么变：ε 越小，N 越大——这就是「任意小」。"
}
```

| 字段 | 说明 |
|---|---|
| `expr` | 通项表达式，自变量是 **`n`** |
| `nrange` | 画到第几项 `[n1, n2]`，建议 `n2 ≥ 40` |
| `target` | 极限值 a（画水平虚线 + ε 带中心） |
| `sliders` | **必须有一个名为 `eps`** 的滑块 |

自动计算并标注 **N**（此后所有项都落入 ε 带），红点＝带外的项，绿点＝带内的项。

## 五、`matrix2`：线性变换 / 行列式 / 秩

```interactive
{
  "type": "matrix2",
  "range": [-3, 3],
  "sliders": [
    {"name": "a", "label": "a", "min": -2, "max": 2, "step": 0.05, "value": 2},
    {"name": "b", "label": "b", "min": -2, "max": 2, "step": 0.05, "value": 0},
    {"name": "c", "label": "c", "min": -2, "max": 2, "step": 0.05, "value": 0},
    {"name": "d", "label": "d", "min": -2, "max": 2, "step": 0.05, "value": 1.5}
  ],
  "hint": "拖到 ad−bc=0（例如让 a=0 且 c=0）：单位正方形被压扁成一条线段，秩从 2 掉到 1。"

```

自动显示 `det`、`秩`、像的形状（整个平面 / 一条直线 / 一个点）。

## 七、`concept-map`：知识图谱（F6 专用）

支持两种写法：**简单行格式**（推荐，手写友好）或 JSON。

```concept-map
concept: 一致连续
course: 数学分析 · 函数连续性
down: 函数, 极限, 连续, 区间
up: 闭区间上连续函数性质（Cantor 定理）, 一致收敛, 可积性
lateral: 连续
note: 从「局部」走向「整体」的第一个范例
```

| 键 | 必填 | 说明 |
|---|---|---|
| `concept` | ✅ | 中心概念 |
| `course` | | 所属课程 · 章节（显示在中心节点上方） |
| `down` | ✅ | **下楼（前置）**：它建立在哪些概念之上；多个用 `,` `，` `、` 分隔 |
| `up` | ✅ | **上楼（后续）**：由它能推出什么；多个同上 |
| `lateral` | | **平移（同类 / 对偶）**：如「连续」（与一致连续对偶） |
| `note` | | 一句话定位（图底部） |

- `down` 节点在左、`up` 在右、`lateral` 在下（双向虚线）。
- 每侧建议 **2–4 个**，总数不超过 9 个，否则图会挤。
- 概念名要**短**（4–10 字），过长会自动缩字号。

## 八、`geogebra`：让学生自己在 GeoGebra 里复现

```geogebra
f(x) = sin(1/x)
SetColor(f, 0.18, 0.44, 0.70)
d = Slider(0.005, 0.25, 0.005)
x_0 = Slider(0.03, 0.9, 0.01)
A = (x_0, f(x_0))
B = (x_0 + d, f(x_0 + d))
s = Segment(A, B)
SetColor(s, 0.76, 0.35, 0.17)
eps = Slider(0.1, 1.3, 0.05)
g: y = f(x_0) + eps
h: y = f(x_0) - eps
```

**规则**：
1. **每行一条命令**，学生可逐行粘贴到 GeoGebra 输入栏。
2. 颜色用 **RGB 三数**形式 `SetColor(obj, r, g, b)`（取值 0–1）——最稳，不依赖颜色名支持。
3. 用 `Slider(min, max, increment)` 建滑动条。
4. 装饰性命令（`SetColor` / `SetLineStyle`）放在最后，并提示「若报错可整行删掉，不影响图形」。
5. 指令必须和卡片上的 `interactive` 组件**讲同一件事**（学生能对照着做）。
6. 不确定某命令在你版本里是否可用时，**宁可不写**，只给核心的 `f(x)=...`、`Slider(...)`、取点连线。

## 九、`sim` / `calc`：Python / R 代码选项卡

### 什么时候用（不是每个概念都要）

模拟代码演示的是**滑块图形画不出来的东西**：随机性、迭代、大样本下的统计规律。
判断标准一句话：**这件事必须「跑起来」才能看见吗？** 是，才写 sim 块。

| 适合 | 典型概念 |
|---|---|
| 频率 / 样本均值的稳定性 | 大数定律、中心极限定理、依概率收敛 |
| 蒙特卡洛估计 | 用随机投点估 π、估积分 |
| 随机过程的一次实现 | 随机游走、泊松到达、分支过程 |
| 迭代与不动点 | 数值迭代收敛、Logistic 映射 |
| **数值验证反例 / 删条件后果** | F1 的反例、F3 删掉某条件后现象是否仍成立 |

**不适合**：确定性几何关系（用 `interactive`，拖动比读代码直观）；纯结构概念（不硬凑）；能一眼算出来的小例子（直接算）。

**放在哪里**：散布在**需要它的面**——F1（反例数值验证）、F3（删条件实验后果）、F5（随机规律的图形化替身）、自检（「跑这段代码，先猜输出再看」）。**每张卡 ≤ 2 个**；对话输出里不用 sim 块，直接给两个普通代码块。

### 写法

块内用**独占一行**的 `# PYTHON` 和 `# R` 划分语言段（两段讲**同一件事**，默认展示 Python，点标签切 R）；
每个语言段内部按「**计算 → 模拟**」两段组织——**计算**是一条指令直接得到理论 / 精确值（没有可一步
算出的精确值就诚实省略，如纯随机轨迹演示），**模拟**是固定种子的蒙特卡洛验证；空行写成 `#` 注释行；
**每段末尾**用注释给出「预期输出」：

````
```sim
# PYTHON
import numpy as np
rng = np.random.default_rng(1)
# —— 计算：一条指令得到理论值 ——
print("U(0,10) 的期望 =", (0 + 10) / 2)
# —— 模拟：样本均值随 n 怎么走（改编自张敬信《两行代码模拟大数定律》） ——
for n in (100, 1000, 10000, 100000):
    print(f"n = {n:>6}   样本均值 = {rng.uniform(0, 10, n).mean():.4f}")
# 预期输出:
# U(0,10) 的期望 = 5.0
# n =    100 样本均值 = 5.1307
# n =   1000 样本均值 = 5.0408
# n =  10000 样本均值 = 5.0196
# n = 100000 样本均值 = 4.9973
# R
suppressMessages(library(tidyverse))
# —— 计算：一条指令得到理论值 ——
print((0 + 10) / 2)
# —— 模拟：样本均值随 n 怎么走 ——
set.seed(1)
print(tibble(n = c(100, 1000, 10000, 100000),
       `样本均值` = map_dbl(n, \(k) mean(runif(k, 0, 10)))))
# 预期输出:（R 4.6.1 实跑；随机数生成器与 Python 不同，数值不必相同，均贴近 5）
# [1] 5
# # A tibble: 4 × 2
#       n 样本均值
#   <dbl>    <dbl>
# 1   100     5.18
# 2  1000     4.97
# 3 10000     5.00
# 4 100000    4.99
```
````

### 规则（违反即回改）

1. **两段同一件事**：Python 和 R 演示同一个现象、输出同一种量——不是「Python 版 + 随便凑个 R 版」。
2. **计算 + 模拟，各司其职**：有精确答案的概念，**计算**给「一条指令得到理论值」的示范
   （`(0 + 10) / 2`、`0.25 / (n * eps^2)`、`pnorm(1.96) - pnorm(-1.96)` 这类），**模拟**负责
   「跑起来看现象」——先算后模拟，学生才知道模拟该贴着哪条线。纯轨迹类演示（随机游走的一次实现）
   没有一步可算的精确值，诚实省略计算段。
3. **随机必固定种子**：Python `np.random.default_rng(seed)`（或 `random.seed`），R `set.seed(...)`——
   否则「预期输出」不可复现，模拟就不构成证据。注意两种语言随机数生成器不同，**同种子结果也不同**，
   R 段的预期输出**实跑后照实写**，不照抄 Python 的数字。
4. **向量化（代码风格的第一纪律）**：抽样与统计计算**不写逐元素循环**——
   Python 用 numpy：一次生成 `rng.uniform(0, 10, n)` / `rng.binomial(n, p, B)`，再整体 `.mean()`；
   R 用 tidyverse：`tibble` + `map_dbl(\(k) mean(runif(k, 0, 10)))`，或基础包等价写法 `sapply`。
   for 循环只允许两种正当用途：**多档参数的展示**（循环 n ∈ {100, 1000, …} 打印）与
   **真正的迭代递推**（Logistic 映射、不动点迭代——这种没法向量化）。
   风格参照：张敬信《【Tidyverse优雅编程】概率论：两行代码模拟大数定律》。
5. **只输出文本**：`print` / `cat` 出**数字与结论**，不 import 绘图库（弹窗依赖显示环境）；
   要「看图」的演示交给 `interactive` 组件。R 段统一用 `print(...)` 显式打印（写成脚本跑也有输出）。
6. **预期输出必须实跑**：生成卡时**当场运行**两段代码——本机有 Python / R 环境就**必须实跑**
   （`python check_card.py 卡.md --run` 可机械执行：解释器找不到才跳过并明说），把**真实输出**
   粘进 `# 预期输出:` 注释；本机连一个可用环境都没有时才允许定性描述并标注。
   实跑需要 numpy / tidyverse：没有就先补环境（`uv pip install numpy` 等）再跑闸门。
7. **配引导语**：块前一行话说清「跑什么、看什么、先猜什么」，和 F5 的操作引导语同一纪律。
8. **代码要短**：每段代码 ≤ 10 行；向量化之后理应如此——**能读懂比能跑通更多功能重要**。

### 卡片里的呈现

- 屏幕上：选项卡默认 **Python**，点 **R** 切换；右上角「复制代码」复制当前语言的代码。
- 打印时：选项卡消失，Python、R 两段**全部展示**，各带一行语言标签（纸质版内容不缺失）。

### `calc`：概念计算器（确定性计算，F5 之后单放一节）

`sim` 演示「跑起来才看得见」的随机 / 迭代规律；`calc` 给的是**确定性**的概念量化工具——
**一个函数（或一条指令），输入参数、输出结果**：$\varepsilon\to N$、$n\to$ 上界、矩阵 $\to$ 秩、
区间 $\to$ 积分近似值……学生改一个参数，就能看到概念里的量随之怎么变；手算易错的量交给它算。

**什么时候用**：概念自带一个「能由定义或公式算出数」的量，且值得反复调参观察。
判断标准一句话：**这是一个「函数」吗？** 是，就把这个函数连同一次示例调用写进 `calc` 块。

| 适合 | 典型概念 |
|---|---|
| 定义里存在量词的「反求」 | ε → N（数列极限）、ε → δ（一致连续） |
| 上界 / 不等式给出的量 | 切比雪夫界、误差估计 |
| 结构性数值 | 矩阵的秩 / 行列式、向量组相关性判定 |
| 由公式一步得到 | 积分近似、级数部分和、期望 / 方差 |

**不适合**：随机 / 迭代现象（用 `sim`）；能一眼算出的小例子（直接算）；几何关系（用 `interactive`）。

**写法**：与 `sim` **完全相同**——`# PYTHON` / `# R` 两段、两段讲同一件事、各带 `# 预期输出:`。
差别只有两点：

1. **必须确定性**：不写随机数（写了 `check_card.py` 会警告，建议改 `sim`）；因此无需固定种子。
2. 代码主体是**函数定义 + 一次示例调用**（体现「输入 → 输出」），不是蒙特卡洛循环。

````
# PYTHON
import math
def N_for(eps):              # a_n = 1/n：使 n > N 时 1/n < eps
    return math.ceil(1 / eps)
for eps in (0.1, 0.01, 0.001):
    print(f"eps={eps:<6} N={N_for(eps)}")
# 预期输出:
# eps=0.1    N=10
# eps=0.01   N=100
# eps=0.001  N=1000
# R
N_for = \(eps) ceiling(1 / eps)
for (eps in c(0.1, 0.01, 0.001)) cat(sprintf("eps=%-6g N=%d\n", eps, N_for(eps)))
# 预期输出:
# eps=0.1    N=10
# eps=0.01   N=100
# eps=0.001  N=1000
```
````
