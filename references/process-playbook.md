# 过程手册：解题 · 自测 · 反例 · 诊断

> 六棱镜解决「**讲清楚**一个概念」；本手册解决「**用得上**一个概念」。
> 学生真正卡住的，往往不是「听不懂」，而是四个更具体的问题：
> **不知道从哪儿下手做题 / 不知道自己算不算懂了 / 不知道怎么找反例 / 不知道自己为什么会错。**
>
> 四件工具，每件都是可直接照做的**程序**，**不依赖任何具体概念**，也不依赖任何外部资料。

---

## 一、通用求解程序：「两头往中间」

> **大学数学没有多少解题技巧，只有一套解题方法：定义 + 基本逻辑推理。**
> 落到实处就是一句话：**把题设的定义展开，把结论的定义展开，从两头往中间推，用基本逻辑推理把两块接上。**

### 四步

| 步 | 动作 | 自问 |
|---|---|---|
| **① 拆题设** | 把题目**给的条件**逐条翻译成「它对应哪个定义 / 定理的哪个前提」 | 每个条件，我在**定义**里见过它吗？ |
| **② 拆结论** | 把**要证的结论**翻译成「它对应哪个定义 / 定理的哪个结论」 | 要证的东西，长得像**哪个定义的后半句**？ |
| **③ 两头夹** | 从**结论**倒着找「还差什么才套得上定义」，再回**题设**看哪个条件正好补上这个缺口 | 我还差什么？题设里有没有现成的一块？ |
| **④ 顺写** | 从题设正向重写一遍，**每一步都注明依据**（哪条定义 / 定理 / 已证结论） | 这一步的依据是什么？说不出来就是跳步 |

### 为什么第 ③ 步必须「从结论往回看」

正向硬推，很容易在中间卡死；从**结论**倒着看，常常一眼就发现「只要再多一个 $f(0)=0$ 就套得上定义了」——而题设里恰好藏着这句话。
**多数证明题的钥匙在这里，不在正向推。**

> **与 F3「操作骨架」的分工**：
> **操作骨架** = 「某一类定义怎么用」的固定写法（如 ε–N 证明的四步）；
> **两头往中间** = 「拿到任意一道题怎么开局」的通用程序。
> 先有开局，再用骨架。**骨架是肌肉记忆，程序是行动路线。**

### 这不是套路，恰恰是「反套路」

套路是「见到 A 就套 B」，靠**记忆**；本程序每一步都回到**定义**，靠**推理**。
所以它对**没见过的题同样有效**——这正是它与「题型总结」的本质区别。

### 一例（同一个程序，换个概念照样跑）

**题**：设 $f$ 在 $x_0$ 连续，证明 $\lvert f\rvert$ 在 $x_0$ 连续。

- **① 拆题设**：「$f$ 在 $x_0$ 连续」→ 展开成定义：
  $\forall\varepsilon>0\ \exists\delta>0,\ \forall x:\ \lvert x-x_0\rvert<\delta \implies \lvert f(x)-f(x_0)\rvert<\varepsilon$。
- **② 拆结论**：「$\lvert f\rvert$ 在 $x_0$ 连续」→ 要证：
  $\forall\varepsilon>0\ \exists\delta>0:\ \bigl\lvert\lvert f(x)\rvert-\lvert f(x_0)\rvert\bigr\rvert<\varepsilon$。
- **③ 两头夹**：两边一对照，**只差一步**——由三角不等式
  $\bigl\lvert\lvert f(x)\rvert-\lvert f(x_0)\rvert\bigr\rvert\le\lvert f(x)-f(x_0)\rvert$。
  于是题设给的 $\varepsilon$ 与同一个 $\delta$ 正好顶上，缺口补上了。
- **④ 顺写**：任给 $\varepsilon>0$，取题设所给之 $\delta$；当 $\lvert x-x_0\rvert<\delta$ 时，
  由题设得 $\lvert f(x)-f(x_0)\rvert<\varepsilon$，再由三角不等式得 $\bigl\lvert\lvert f(x)\rvert-\lvert f(x_0)\rvert\bigr\rvert<\varepsilon$。∎

> **看清楚：结论里那「差一步」，正是 ① 展开的定义自动补上的。** 这就是这个程序的全部威力。

### 拿它做开局，三个概念各跑一遍

| 概念 | ① 题设拆成 | ② 结论拆成 | ③ 缺的那一步 |
|---|---|---|---|
| 数列极限 | 「$\lvert a_n-a\rvert$ 可以任意小」 | 「$\forall\varepsilon>0\ \exists N\dots$」 | 把不等式**反解出 $N(\varepsilon)$** |
| 一致连续 | 「$\lvert x_1-x_2\rvert<\delta$」 | 「$\forall\varepsilon\ \exists\delta\ \forall x_1,x_2\dots$」 | 找一个**不依赖位置**的 $\delta$ |
| 线性无关 | 「$\sum k_i\alpha_i=0$」 | 「$k_1=\dots=k_s=0$」 | 把向量等式**拆成方程组**再解 |

## 二、理解度判据：怎么知道自己「真懂了」

「懂了」不是感觉，是**可勾选的三条**：

| # | 判据 | 自测方式 |
|---|---|---|
| **1 字字清** | 概念表述里**每个字眼**都说得清意思，说得出它的几何 / 物理背景，说得出它与哪些相关概念**怎么联系** | 把定义读给你自己听，逐词问「这个词删了会怎样」 |
| **2 证得明** | 能用**已学的知识**解释相关定理，能**默写推导**出定理的证明过程 | 合上书，默写一条相关定理的证明，**每一步标依据** |
| **3 画得出** | 能默写梳理出这个概念周边的**知识体系**（前置 / 后续 / 对偶） | 白纸上画它的知识图谱，标出关系方向 |

> **判据：至少完成一半，再去做题也不迟。**
> 做题的目的是**验证**掌握，不是掌握本身——没到一半就刷题，等于拿没校准的尺子去量。

### 配套工具：「条件反射清单」

「懂了」还有一个很具体的模样：**说到某个概念，你能一口气说出好几条，而不是只背得出一个公式。**

格式：**「说到『X』，你要想到：……」**（闭卷写，写不出说明没挂进体系）

**范例（数列极限）**：
1. ε–N 定义，量词顺序是 $\forall\varepsilon\ \exists N\ \forall n>N$；
2. 几何：数轴上一把可任意缩小的「尺子」，带外只剩**有限多项**；
3. 与**函数极限**是同一模板（离散 $n\to\infty$ ↔ 连续 $x\to x_0$）；
4. **有界是必要不充分**（反例 $a_n=(-1)^n$）；
5. 与**子列**的关系：任一子列都收敛于同一值；
6. **Cauchy 列**是不用预知极限值的等价刻画（依赖实数完备性）。

**其他概念**：
- 说到「连续」→ 三条（有定义 / 极限存在 / 极限值等于函数值）+ 几何「不断开」+ 与可导的关系（可导必连续，反之不然）+ 闭区间上连续的三条大定理 + 与一致连续的区别。
- 说到「可导」→ 定义（差商极限）+ 几何（切线斜率）+ 可导 ⇒ 连续 + 可导 ⟺ 可微 + 左右导数 + 求导法则的来源。

> **检验线**：闭卷给自己 60 秒，能连续说出 **≥4 条**才算过。只说得出 1 条（通常是定义），说明还没建立联系。

## 三、反例构造手法（F1 没反例可给时，从这里找）

反例不是「灵光一闪想出来的」，是**按手法造出来的**。六种常用手法：

| 手法 | 怎么造 | 经典例子 |
|---|---|---|
| **① 推边界** | 把参数推到端点 / 临界值 | $\ln n$ 相邻项距离 $\to 0$ 却发散；$\dfrac1x$ 在 $(0,1)$ 上连续但不一致连续 |
| **② 造振荡** | 让对象在两个值之间来回跳 | $(-1)^n$（有界不收敛）；$\sin\dfrac1x$（$x\to0$ 无极限） |
| **③ 换定义域** | 函数不动，只改定义域 | $x^2$ 在 $[0,1]$ 上一致连续，在 $\mathbb{R}$ 上不 |
| **④ 取退化值** | 代入零元 / 特殊元 | 含零向量的向量组必线性相关；单个零向量线性相关 |
| **⑤ 造子列** | 让一个子列达标、另一个不达标 | $\dfrac1x\sin\dfrac1x$（$x\to0$）：有子列 $\to\infty$ 故无界，又有子列恒为 $0$，故不是无穷大 |
| **⑥ 造「坏点对」** | 要否定「$\exists\delta$」型命题，就造两列点使**距离 $\to0$ 而像距不 $\to0$** | $\dfrac1x$ 在 $(0,1)$：取 $x_n=\dfrac1n,\ y_n=\dfrac1{n+1}$，则 $\lvert x_n-y_n\rvert\to0$，但 $\lvert f(x_n)-f(y_n)\rvert=1\not\to0$ |

### 造完必须验算（纪律红线 8）

每一个反例，**代进定义算一遍**再写。
**算不出来的，不写**——改成「请你试着构造一个反例」（把这一步还给学生）。
> 反面教训：判断 $a_n=(-1)^n$ 的奇偶项时把「奇数项 $=-1$、偶数项 $=+1$」写反——**结论对、举证错，学生照样被带偏**。

## 四、误区来源诊断（F0 诊断题的靶心）

学生的错，常常不是「不小心」，而是**有来源**。**先判来源，再出题**——诊断题打不中来源，就是白问。

| 来源 | 典型表现 | 对症的处置 |
|---|---|---|
| **中学残留** | 「越来越接近就是收敛」「函数就是一条不断的曲线」 | 用**边界例**打碎直觉（$\ln n$；$\sin\frac1x$） |
| **教材省略** | 教材直接拿某个等价条件当定义，学生没见过全貌 | 把**被省略的那几条**补出来，并说明教材为什么省（省不等于错） |
| **字眼漏读** | 定义里的「任意」「存在」「从某项起」「不全为零」没读到 | **删条件实验**，让反例自己冒出来 |
| **量词顺序** | 把 $\exists\delta\ \forall x$ 当成 $\forall x\ \exists\delta$ | 量词交换反例（连续 vs 一致连续） |
| **定理当定义** | 把派生性质（可导必连续、行秩 = 列秩）当成定义去「证」 | **三种身份辨别表**（定义 / 定理 / 约定） |
| **类比越界** | 把类比推过头（把「尺子」类比当成证明） | 补**类比失效边界**，并声明「类比只帮想到，不帮证明」 |

> **用法**：第 0 步写假设基底时，先看学生可能落在哪一行；第 1 步的诊断题就照那一行的「对症处置」来出。
> 一句话：**诊断题不是随机抽查，是照着误区的来源精准下钩。**
